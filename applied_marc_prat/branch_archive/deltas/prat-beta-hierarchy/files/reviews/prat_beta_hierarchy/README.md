## 0. 结论

**任务 1（β）**
1. Prat 附录的 β = 2 是一个**运动学**陈述：生长面积 A = 24 d_t²（A1）、晶体体积 V_c = 4 d_t³（A2）、层厚 h = d_t + e（A5），故 dh/dt = ḋ_t = [A/(dV_c/dd_t)] v_face = 2 v_face。它等价于"自由立方晶六面同速生长时棱长增速是面速的两倍"。
2. 保持 β = 2 的相似变换：均匀缩放 d_t → λd_t（A ∝ d²、V ∝ d³）；改变间隙 e（即孔隙率）——e 根本不进入 A1–A4；横向复制晶胞。所以 β 与 d_sub、ε_s、层数无关是**构造**出来的，不是推导出来的。
3. 使 β ≠ 2 的形态变化：面被接触/未润湿封锁（β = 2 − n_blocked/3：底面附着 5/3，三面接触 1，仅顶面 1/3）；非立方习性（空心漏斗晶 3.5，沿长轴生长的针状晶 4L/d + 2 ≫ 2）；面依赖的 k_r；层厚约定（A5 的 h = d_t + e 与图 3 的 d_f + e/2）；以及把"整个顶层晶面都在长"作为界面汇（质量平衡观点 β_mb = a_v d_c/(1−ε) = 5）。这些都不是立方晶胞的相似变换，Prat 自己也写明式 20 右端是"postulated"。
4. 灵敏度：Da* ∝ β²，d ln F/d ln β = 1 − F（粗基底 0.05，细层 0.5），C*_top ∝ 1/[β(1−ε)(1−C_eq)k_r + 常数]，结壳临界晶粒 d_c,crit ∝ β⁻²，r = 1/2 时 **β 每乘 √2 结壳层推后一层**（线性化参考解逐一复现：β = √2/2/2√2 → 第 3/4/5 层）。
5. **β 扫描不是几何律的证明**：它给出"若 β 在 [1, 6] 内，结壳层在第 2–6 层之间"这一区间，不能从 2014 的 60–100 µm 转变反推 β；β 的值要靠晶体尺度的观测（哪些面在长、是否润湿、习性）或形式上尺度化来定。

**任务 2（层叠）**
6. 反应–输运决定的是：每层的 F_n、ε_final,n、C*_top,n 与**结壳层序号 n\***（d_c(n) < d_c,crit）。预设几何决定的是：晶粒序列 d_c(n) = 0.14 d_sub r^(n−1) 本身（r）、结壳**高度** h* = c_h d_sub (α^(n*−1)−1)/(α−1) 和时间（α、c_h）。α、c_h 不进入任何反应–输运量；数值扫描里它们只平移 h*，F 平台与 n* 不变到 1e-3。
7. h* ∝ d_sub^m 的指数 m = 1 + ln α/ln(1/r) 是纯几何（plan/13）；只有前因子（经 d_c,crit ∝ D_eff(1−ε)/(β² ε (1−C_eq) k_r)）是物理。r 改变 n*（0.4 → 第 3 层，0.7 → 第 6 层），线性化参考解与解析 n* 逐一相符；自洽变体的推后随 r 增大（r 0.5：+1 层，r 0.6：+2 层，r 0.7：≥ +2），因为相邻层的 F 差越小，同样的局部 Da* 抬升跨越的层数越多。
8. 层间过渡是准稳态的：过渡瞬态几个 δ_C/v（秒–分钟），远小于层穿越时间（小时）；"每层一个 F"在时间上成立。
9. 求解器在层属性间断处：F 平台对 n_band 20–160、dt ×0.2–×4、拉伸 1.015、窗口 120 δ_C、调和/算术面平均都不变到 1e-3；过渡瞬态 2–4 δ_C/v。**原求解器的一个缺陷**：结壳在每个 Picard 迭代上判定，首个迭代用滞后的汇，dt ≥ 2 δ_C/v 时提前一层封孔（第 4 层而非第 5 层）；改为在收敛步上判定（扩展副本 `closure_check="converged"`）后结壳层对 dt 0.5–4 δ_C/v 不变、结壳高度每 4 倍 dt 移动 < 1 δ_C。前一审查的所有结果用 dt = 0.5 δ_C/v，两种判定一致，结论不受影响。记录的 ε_final(z) 跳变宽度（8–17 µm）是窗口底部粗格的逆风数值扩散（随拉伸缩小、随窗口增大），不影响每层中位数与结壳。
10. ε_final 解读的"不可达"须改述为**有限扫描**陈述：对 0.24 µm 晶粒，ε_new ≤ 0.99 时两套网格都到不了 0.43（线性化模型在 ε_new ≈ 0.93 可达）；ε_new > 0.99 时出现一条**依赖网格**的可达窄带（n_band 40：仅 0.998；80：≥ 0.994），那里 a_v = 5(1−ε)/d_c → 0 使带内惰性、ε_final ≈ ε_new——堆积公式在 99 % 空隙处无意义，数值也未收敛。前一审查的说法"[0.43, 0.99] 内无解"成立，"对一切 ε_new 不可达"不成立。

## 1. β：从附录晶胞到灵敏度（`beta_analysis.py`；`results/beta_analysis.md`、`beta_*.json`；`figures/beta_sweep.png`）

### 1.1 推导（Prat 附录 A1–A5，图 3）

附录定义：生长面（"假设溶液存在于所有表面"）A(t) = 6d_t² + 4[2(d_t/2)d_t + 2(d_t/2)²] + 4[d_t² + 4(d_t/2)d_t] = 24 d_t²；
新层晶体体积 V_c = d_t³(1+1+2) = 4d_t³；沉淀 dV_c/dt = A k_r (ρ/ρ_cr)(C_top − C_sat)（A3，ρ/ρ_cr 在 A6 中）；层厚 h = d_t + e（A5）。
于是 12 d_t² ḋ_t = 24 d_t² v_face，ḋ_t = 2 v_face，dh/dt = ḋ_t：

    β ≡ A / (dV_c/dd_t) = 24/12 = 2.

**它为什么是 2**：对任何由等大自由立方晶（六面同速生长）组成的集合，A = 6Nd²，dV/dd = 3Nd²，比值恒为 2——"棱长增速 = 2 × 面速"。晶胞的具体拼法（一个整块 + 半块）只是把 N 取成 4。

**保持 β = 2 的变换**：
- 缩放 d_t → λ d_t：A ∝ d²、dV/dd ∝ d² → β 不变（数值核对 d = 1 与 7.3）。
- 改变间隙 e：e 不进入 A1–A4（只进入 A5 的 h），所以 β 与孔隙率无关——注意这意味着 β = 2 不是"对 ε_s = 0.43 推出的"，它对任何 ε 都是 2，因而也不能用它区分疏松与致密结构。
- 横向复制晶胞（N 个）：A 与 dV/dd 同乘 N。
- 任何等大、六面全长、全润湿的立方晶集合。

**使 β ≠ 2 的变化**（`beta_analysis.py` §A 的表）：

| 晶胞 / 习性 | β |
|---|---|
| 附录晶胞（A1, A2） | 2.000 |
| 一个自由立方晶 | 2.000 |
| 底面附着（五面长） | 1.667 |
| 底面 + 两侧接触（三面长） | 1.000 |
| 仅顶面长（逐层覆盖生长） | 0.333 |
| 空心漏斗晶，壁厚 0.2 d，内壁润湿 | 3.47 |
| 针状 d×d×L，h 沿长轴、只有 L 在长 | 4L/d + 2（L = 10d：42） |

此外：(i) 面依赖的 k_r（NaCl {100} 各面等价，但杂质/溶液流动会打破）；(ii) 层厚约定：图 3 右侧标 "d_f + e/2"，附录 A5 用 d_t + e，两者的 dh/dt 相同（e 常数）但对"h"的定义不同；(iii) 质量平衡观点：若把整个顶层晶面都当生长面，每单位宏观面积的生长面 = a_v d_c = 5(1−ε)，β_mb = 5——Prat 的 2 对应的是从小核长到 d_f 的晶体（图 3 左），不是已成型层的继续增厚。这两种图像给出的界面汇差 2.5 倍，哪种更接近真实，附录没有论证；Prat 明言"the right-hand side of eq 20 has not been derived … but simply postulated"。
(iv) Wijnhorst 2025 的 micro-CT 显示部分立方晶空心——漏斗晶的生长面/体积比高于实心立方，β 偏大的方向。

### 1.2 解析灵敏度

    Da* = β²(1−ε)²(1−C_eq)k_r/(ε D_eff a_v) ∝ β²;   F = √Da*/(1+√Da*);   d ln F/d ln β = 1 − F
    C*_top = U_evap C_eq / [β(1−ε)(1−C_eq)k_r + √((1−C_eq)a_v k_r ε D_eff)]
    d_c,crit = 5 D_eff (1−ε) / (β² ε (1−C_eq) k_r)        (F = 1−ε 处)
    n* = 2 + floor( ln(0.14 d_sub/d_c,crit) / ln(1/r) )     (r < 1)

r = 1/2 时 n* 随 log₂(β²) 移动：β 每乘 √2，n* + 1。

### 1.3 数值扫描

### 1.4 β 扫描不能证明什么

扫描只回答"若 β = x，模型给什么"。它不能：(a) 从 2014 的转变粒径反推 β（同一 n* 可由 β、k_r、D_s、ε、r 的多种组合给出——Da* 只含乘积 β² k_r/(D_s a_v)，与 k_r 完全简并）；(b) 验证立方晶胞的任何一条假设（全润湿、六面同速、层厚 = 棱长）；(c) 区分 Prat 的"小核长大"图像与"顶层增厚"图像（β 2 vs 5）。要定 β，需要晶体尺度的直接观测（顶层晶体的生长面、润湿状态、习性）或形式上尺度化（Prat 自己建议的 ref 28 路线）。

## 3. 求解器在层属性间断处的审计（`solver_audit.py`；`results/solver_audit.md`、`audit_*.json`；`figures/audit_transition.png`、`audit_infeasibility.png`）

间断的来源：材料坐标 z_m = h − ξ 跨层边界时，格内的 d_c、ε_new、a_v 跳变；ε 场由隐式逆风平流；εD 在面上取算术平均。
审计项目：(A) 第 2→3 层过渡与结壳对 n_band、dt、拉伸、窗口、面平均、变体、结壳判定方式的依赖；(B) 记录的 ε_final(z) 跳变宽度；(C) ε_final 不可达声明的加密扫描。结果见 §5.3。

其他已查明但无需修改的点：(i) 跨层边界的格以格心所在层取属性，边界位置误差 ≤ Δξ（带内 ≤ δ_C/40）；(ii) ε 的隐式逆风平流在带内（细格）不产生可见扩散，在窗口底部（粗格）产生 §5.3 的跳变展宽；(iii) 线性化变体的累计固体残差 1e-7（其余 1e-11）：孔隙率更新用的是上一 Picard 迭代的汇，在结壳前的最后几步差异累计——不影响任何结论，但说明两套平衡应在同一迭代上评价；(iv) 结壳判定（见 §0 第 9 条）。
