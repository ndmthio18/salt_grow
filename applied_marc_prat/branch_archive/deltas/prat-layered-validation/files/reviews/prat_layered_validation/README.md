## 0. 结论

**已验证的数学结果**（参考解对 Prat 自己的线性化问题的复现，精度 1e-4）：

1. Prat 式 (29)、(31)、(19) 是方程 (1)–(3)、(6)、(7)、(20) 在"输运算子中 ε 取出生值、液相平衡 (3)–(4) 保留"这一混合线性化下的精确稳态解。参考解在该设定下复现 dh/dt、C*_top、剖面到 ≤ 3e-4（网格一阶收敛，平台 5e-5 来自 Prat 丢掉的 C_top≈C_eq 与带内对流项）。
2. **式 (29) 预设了它所否认的孔隙率下降。** 式 (5) 的 (1−C) 因子来自式 (3) 与式 (2) 的联立——沉淀吞掉的孔体积。把 ε 在所有方程里都固定（字面的"自复制"），前沿速度比式 (29) **低** 3.4 %（10 µm）到 0.5 %（1080 µm）；去掉式 (3)–(4) 的液相消耗，(1−C_eq) 因子消失，δ_C 缩 √(1−C_eq)，F 相应下降（25 µm：0.731 → 0.700，解析可核）。
3. 本项目的闭合 ε_birth = 1 − (1−ε_s)/F(Da*) 是该线性化下带内沉淀的精确结果（10 µm：0.0981 vs 0.0980）。
4. 分层结构上，逐层 Prat (B) 在"ε_new 解读"下的结壳层（F_n < 1−ε_s）被线性化参考解精确复现：27.5 µm、ε_s 0.43 时第 4 层，h = 193 µm，t = 2.1 h（1 cm/day）。

**额外物理闭合的后果**（Prat 自己的 a_v = 5(1−ε)/d_c、D_eff = √ε D_s 在带内按**局部** ε 评价，而不是按出生值）：

5. 带内致密化提高局部 Da*：前沿比式 (29) 快 5.5 %（10 µm）→ 0.06 %（1080 µm），终态孔隙率比闭合值高（10 µm：0.145 vs 0.098；25 µm：0.237 vs 0.220）。偏差随 d_sub 单调减小。
6. 分层结构：每层 F 高于逐层 Prat，结壳推迟一层（27.5 µm：第 5 层，h = 413 µm，t = 4.6 h）。
7. **ε_final 解读在自洽模型中并不总能消除结壳极限。** 线性化模型里任何目标终态孔隙率都有对应的出生孔隙率（1−ε_new = F(1−ε_final)），但在局部 a_v 反馈下，27.5 µm 第 5 层晶粒（0.24 µm）无论 ε_new 取 [0.43, 0.99] 中何值，终态都到不了 0.43；第 7 层晶粒（0.06 µm）对一切 ε_new 都封孔。ε_final 解读把极限推后但没有去掉。

这些都是 Prat 方程组自身的推论（含其 a_v、D_eff 闭合），不含本项目的其他假设。它们**不**回答 ε_s 的两种解读哪个对——那仍需实验（见审计 §1.3）。

## 1. 求解的方程（物理模型）

Prat (2026) 式号；推导核对自 `../salt_grow/reference/Marc Prat 2026 ….md` §2–3、§7：

    (1)  ∂(ρεC)/∂t + ∂(ρCU)/∂z = ∂(ρ ε D_eff ∂C/∂z)/∂z − a_v ρ k_r (C − C_eq)
    (2)  −ρ_cr ∂ε/∂t = a_v ρ k_r (C − C_eq)
    (3)  ∂(ρε)/∂t + ∂(ρU)/∂z = −a_v ρ k_r (C − C_eq)                 ρ 常数（式 4）
    (6)  ρU = [ρε + ρ_cr(1−ε)] dh/dt + j                              z = h（ρ_v 略）
    (7)  ρCU − ρ ε D_eff ∂C/∂z = [ρCε + ρ_cr(1−ε)] dh/dt              z = h
    (20) dh/dt = β (ρ/ρ_cr) k_r (C_top − C_eq)                         界面动力学
         C(0) = C_eq                                                   基底侧

**不**使用式 (29) 或任何解析生长律：dh/dt 由式 (20) 与数值解出的 C_top 给出。式 (29)、(31)、(19) 只在 `prat_analytic` 里单独算出用于比较。

分层：材料所在高度 z_m = h(t) − ξ 决定其层 n（与 `saltv2/growth/crust.py` 的 `generation` 同约定：h_1 = c_h d_sub，h_n = α^(n−1) h_1），晶粒 d_c(n) = 0.14 d_sub r^(n−1)，出生孔隙率 ε_new(n)。
a_v = 5(1−ε)/d_c（式 16）、D_eff = √ε D_s（式 17 后）按局部 ε 评价（`local_props=True`）或按出生 ε（`False`）。
参数：Prat 基准（C_eq 0.264、ρ 1200 [B]、ρ_cr 2170、β 2、k_r 2.3e-3、D_s 1.3e-9），U_evap = 1 cm/day（论文 Fig. 6 文字的例子）。本项目 baseline 用 D_s = 1.54e-9、k_r(T)，Da* 差 18 %，结论不变。

## 2. 数值方法

界面随动坐标 ξ = h − z，窗口 0 ≤ ξ ≤ L（L = 60 δ_C,1；C→C_eq 按式 19 指数衰减，L 从 30 到 120 δ_C 结果不变到 1e-9）。在该坐标下 (1)–(3) 的精确变换：

    ∂(ρεC)/∂t|ξ + ∂/∂ξ[ −ρ C W − ρ ε D ∂C/∂ξ ] = −S,   S = a_v ρ k_r (C−C_eq),  W = U − ε v（相对坐标系的 Darcy 通量）
    ∂ε/∂t|ξ + v ∂ε/∂ξ = −S/ρ_cr
    ∂ε/∂t|ξ − ∂W/∂ξ = −S/ρ
    ξ=0:  ρ W_i C_top + ρ ε_i D_i ∂C/∂ξ = ρ_cr(1−ε_i) v,  W_i = U_evap + (ρ_cr/ρ)(1−ε_i) v,  v = β(ρ/ρ_cr)k_r(C_top−C_eq)
    ξ=L:  C = C_eq

有限体积，几何拉伸网格（界面处最细，n_band 格/δ_C，比 1.03），后向 Euler，逆风对流，每步 Picard 迭代 (v, ε) 到 1e-10。
ε 是随固体平流的材料场（隐式逆风），不预设剖面。界面闭合 a C_top + b(C_0−C_top) = c(C_top−C_eq) 消去 C_top 后全隐式。
每步报告盐平衡（窗底流入 − 积累 − 界面沉淀 − 带内沉淀）与固体平衡（出生 − 流出 + 带内沉淀 − 积累）的相对残差；整条运行累计残差 ≤ 1e-10（盐）、≤ 1e-7（固体，含结壳前被放弃的最后一步）。
带内孔隙率 ≤ 1e-3 视为封孔：运行停止并记录 `closure_event`（层、h、t），不钳位、不续算。

模型变体（`ReferenceSolver` 的开关）：

| 代号 | evolve_eps | transport_eps_fixed | local_props | liquid_consumption | 含义 |
|---|---|---|---|---|---|
| V0 | 是 | 是 | 否 | 是 | Prat 自己的线性化：带内 ε 下降只进液相平衡与固体，输运算子用出生 ε |
| V2 | 否 | — | 否 | 是 | 所有方程 ε 常数（字面自复制） |
| V3 | 是 | 是 | 否 | 否 | V0 去掉式 (3)–(4) 的液相消耗 |
| P | 是 | 否 | 是 | 是 | 自洽：ε 进每一项，a_v、D_eff 局部 |

r = 0.5、α = 2、c_h = 1（项目的 Wijnhorst 层叠），d_sub = 27.5 / 56 / 112.5 µm（5 层）与 1080 µm（3 层），ε_s = 0.43（主检出的配对）与 0.20（baseline 的 HIERARCHICAL 记录），两种解读。

读法：
- (A) 的 v 与层无关（0.2575 at 27.5 µm），(B) 逐层下降（0.2575 → 0.1746），(C) 在 (B) 之上 2–17 %，差距随层数（晶粒变细）增大：带内致密化抬高局部 Da* 的效应在小晶粒上最强。
- (B) 的结壳判据 F_n < 1−ε_s 被线性化参考解 V0 精确复现（§0 第 4 条；`test_layered_run_closes…`），自洽模型把它推后**一层**，且封孔发生在该层材料进入反应带后 < 3 δ_C（即层底之上 0.1–0.6 µm）——结壳是层属性，不是高度的连续函数。
- (C) 的终态孔隙率总高于闭合值 1−(1−ε_s)/F_n，在最后一层存活层上差一个数量级（27.5/0.43 第 3 层：0.030 vs 0.101）。项目的 ε_birth 闭合在细层上系统性偏致密。
- 层间过渡是准稳态的：过渡瞬态时长 ~ 几个 δ_C/v（≈ 1–3 min）远小于层穿越时间（≥ 0.3 h），所以逐层 Prat 的"每层一个 F"在时间上成立；S3b 的 t_end 对网格收敛到 0.3 %。

|---|---|---|---|
| 27.5, 0.43 | 0.643, 0.730, 0.836, 0.938 | 0.348 | **第 5 层** |
| 27.5, 0.20 | 0.370, 0.460, 0.596, 0.775, 0.939 | 0.248 | **第 6 层** |

| 1080, 0.43 / 0.20 | 0.462–0.496 / 0.222–0.246 | 0.348 / 0.248 | 无 |

读法：
- 前沿速度与层无关、与 F 无关（v = C_eq j/(ρ_cr(1−ε_final)(1−C_eq))），(B) 与 (C) 相同到 1e-3：审计 §1.3 的可辨识性论断在数值上成立。
- 代价是出生孔隙率随层数急升到 0.8–0.94：细层材料得以 ≥ 80 % 空隙出生、随后在 0.2 µm 的反应带内填到 0.43。这是一个很强的微结构断言，没有观测支持。
- **极限没有消失，只是推后**：在自洽模型里，a_v = 5(1−ε)/d_c 随带内致密化增大（正反馈），晶粒 ≤ 0.24 µm（27.5 µm 第 5 层）时 [0.43, 0.99] 内没有任何 ε_new 能把终态做到 0.43（最佳 0.374 @ 0.99，0.999 时反而封孔）；0.06 µm 晶粒对一切 ε_new 封孔。线性化模型 V0 在同一晶粒上可达（ε_new = 0.9 即可，`test_eps_final_interpretation_has_its_own_limit…`）。所以"ε_final 解读下无绝对尺度"只对 Prat 的线性化成立，对他自己的 a_v(ε) 闭合不成立。

## 7. 对项目的含义（建议，不是修改）

1. 主检出的 (A)（第 1 层 F 用于所有层）在 27.5 µm 第 4 层高估前沿速度 47 %（0.2575 vs 0.1746），且永不结壳；这与审计 D6 一致，现在有了定量数值。
2. B′ 的逐层 Da* 与钳位是线性化模型的正确推论；若要用自洽模型，结壳层整体后移一层（27.5/0.43：5；27.5/0.20：4；56/0.20：5），E4/README §19 的触发表需按 §4.1 重算。
3. 项目 `ε_birth` 闭合在细层上偏致密 1 个数量级（§4.1 第三条）；改用局部 a_v(ε) 需要在 `prat2026/core.py` 之外引入 ε(ξ) 的带内解，即本参考解——可作为 `saltv2` 的查表闭合（F_n、ε_final,n 对 d_c、ε_new），不必在体素模型里解带。
4. ε_new / ε_final 的分岔（审计决定 0）：数值上两者的 dh/dt 完全不可辨识；可辨识的只有终态孔隙率与出生孔隙率之差。能判定的实验是测**新鲜顶层**的孔隙率（例如 Wijnhorst 2025 的 SEM 在顶面 vs 深处），或 Licsandru 式的分辨率下读带内梯度。
