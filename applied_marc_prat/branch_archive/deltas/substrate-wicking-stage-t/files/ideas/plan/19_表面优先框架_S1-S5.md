## 0. 结论先行

1. **科学假设（可证伪）**：在芯吸供液下，表面盐结构的命运由四个局部过程的竞争决定：气相扩散给出的局部蒸发（含邻居屏蔽与远场逼近）、
   孔口过饱和与成核、Prat 律把到达盐分配给前沿推进（F 份）与带内沉淀（1−F 份）、毛细供液界限。形貌类别（patchy / crusty）是
   这些过程在阵列上的**统计结果**，不是局部状态。
2. **单尺度、微结构固定的 Prat 结构不会自发产生随时间的封壳转变**（§3.6）：F 不含 j，所以动力学可行性在出生时已定；供液界限的失效高度
   在声明参数下为米量级，远超毫米级实验高度。随时间的转变只能来自覆盖率 / 合并（S4）、气相几何反馈改变 j，或微结构随高度变化
   （分级闭合，后置）。S1–S3 因此只验证局部动力学、守恒与两孔相互作用，**不能**展示 patchy → crusty。
3. **ε_new 是输入 / 状态，ε_final 是预测输出**：1−ε_final = (1−ε_new)/F（稳态）[D]。实测的 0.43 / 0.20 [M Dai, Wijnhorst] 是终态量；
   把它们当 ε_new 是物理假设 [A]，按用户决定作为工作变量使用，并在不确定性表登记。
4. **F < 1−ε_new 是"声明出生孔隙率下前沿稳态解不存在"的可行性判据**，不是封壳的物理证明（§3.3）。
5. **地下**：D-10（10 层 D 拓扑守恒网络）是原型，D-50 是参考；水力高程保持 22 mm（G2），输运深度 7 mm；两者分开记账（§2.3）。
6. **内核**：baseline-selfconsistent 的 `network_step` 与 Stage-T 的 `conservative_step` 是同一组方程的两份实现，先做等价测试再定一份（§6），
   在此之前不加新物理。
7. **S1–S3 的停 / 行判据**在 §8，每条对应一个可计算量。

## 1. 科学问题与观测分类规程

### 1.1 把"形貌"拆成不重叠的量

| 维度 | 量 | 定义 | 测什么过程 |
|---|---|---|---|
| 空间覆盖 | θ(t) | 基底平面被盐覆盖的面积份额 | 成核位密度 × 横向扩展 |
| 空间连通 | κ(t) | 最大盐簇面积 / 总盐面积；是否跨越周期箱 | 合并 |
| 局部生长 | v_i(t) = dh_i/dt、m_i(t) | 每个结构的前沿速度与盐质量 | Prat 律 + 局部 j |
| 局部湿润 | w_i(t) | 结构 i 顶面湿面积份额；湿前沿深度 d_dry,i | 供液与蒸发的平衡（§3.5） |
| 局部堵塞 | ε_final,i、F_i 对 1−ε_new | 带内沉淀后的孔隙率；可行性裕度 | 推进 / 沉淀分配 |
| 输运阻力 | E(t)/E₀ 及其分解 R_gas、R_dry | 总蒸发相对裸基底；气相路径阻力与干盐层阻力 | 几何反馈 |
| 供液 | Π_i = P_cth,i / p_req,i | 毛细阈值对需求压力 | 供液界限 |

### 1.2 观测分类规程（对模型与实验同样适用）

不定义互斥状态；在 (θ, κ, E/E₀) 空间上报告轨迹，并给出**事先声明**的读数：

- "斑块型"读数：θ 在 t_end 前趋于平台且 < θ_p；κ < 1（未跨箱）；E/E₀ ≥ 0.8。
- "封壳型"读数：θ → 1 且 κ = 1（跨箱）；E/E₀ < 0.3，且下降可由 R_dry 或气相连通性丢失解释。
- 两者之间一律报告为"混合"，附 θ、κ、E/E₀ 三个数，不强行归类。

θ_p 等阈值在 S4 之前只作报告格式，不进入任何判据。实验侧对应量：2014 Fig 23 的 E(t)、Ben Amara Fig 7 的高度与扫描覆盖。

## 3. 控制方程与闭合

### 3.1 结构内（Prat 2026，1-D，移动坐标）

```text
∂(ρεC)/∂t + ∂(ρCU)/∂z = ∂(ρε D_eff ∂C/∂z)/∂z − a_v ρ k_r (C − C_eq)        式 (1)
−ρ_cr ∂ε/∂t = a_v ρ k_r (C − C_eq)                                        式 (2)
∂(ρU)/∂z = −a_v ρ k_r (C − C_eq)（液体被结晶消耗）                          式 (3)(4)
a_v = 5(1−ε)/d_c（式 16）；D_eff = √ε D_s；ρ = ρ(C_eq)
```
S1 用其稳态闭合（式 29/31）；S2 积分 (1)(2)(4)（自洽变体：a_v、D_eff 随局部 ε）。参考实现：`reviews/prat_layered_validation/layered_reference.py`，
时间步 ≤ 0.5 δ_C/v [V]。

### 3.2 前沿跳跃条件与精确质量换算（第 3 条）

顶面 z = h（式 6、7，C ≈ C_eq，ρ_v 忽略）：
```text
ρU = [ρ ε_new + ρ_cr (1−ε_new)] v + j                       (6)  液体
ρ C_eq U − ρ ε_new D_eff ∂C/∂z = [ρ C_eq ε_new + ρ_cr (1−ε_new)] v   (7)  盐
```
对整个结构（底部以 C_eq 供液、内部准稳态）做总量守恒：液体 ρU_base = j + ρ ε_new v + S_tot，盐 ρ C_eq U_base = ρ C_eq ε_new v + S_tot，
其中 S_tot 是单位面积总结晶速率。两式消去 U_base：

```text
S_tot = C_eq j / (1 − C_eq)                                   [D] 精确换算：每蒸发 1 kg 水，有 C_eq/(1−C_eq) kg 盐离开溶液
前沿份额  ρ_cr (1−ε_new) v = F · S_tot                        式 (32)(35) 的定义
带内沉淀  I = (1−F) · S_tot = ρ_cr (ε_new − ε_final) v         稳态下带随前沿移动
⇒ v = F C_eq j / [ρ_cr (1−ε_new)(1−C_eq)]                     式 (29) 与 (32) 合并
⇒ 1 − ε_final = (1 − ε_new)/F,  ε_final = 1 − (1−ε_new)/F      [D]
U_base/U_evap = 1 + [ρ ε_new + ρ_cr(1−ε_new)] C_eq F / [ρ_cr(1−ε_new)(1−C_eq)]   式 (33)，U_evap = j/ρ
```
质量一致性要求：**前沿 + 带内 = S_tot**，任何实现里 ledger 的 `salt_grown + salt_front` 之和必须等于 C_eq/(1−C_eq) × 蒸发水量（供液 C = C_eq 时），
而不是只有 F 份（Prat 式 35 只计前沿，少算 1/F；审查 §1 已指出）。
F = √Da*/(1+√Da*)，Da* = β²(1−ε_new)²(1−C_eq) k_r /(ε_new D_eff a_v)（式 27，用 ε_new）。

与现行代码名的对应：`crust.py` 的 `EPS_S` 是 ε_new，`eps_birth = 1 − (1−EPS_S)/F` 是上式的 ε_final（名字相反，审查 D3/M3）。

### 3.3 可行性判据（第 2 条）

1−ε_final = (1−ε_new)/F ≤ 1 ⇔ **F ≥ 1−ε_new**。违反时，在声明的 ε_new 下不存在带随前沿平移的稳态解（带内沉淀超过可填孔隙）。
模型**没有**说明随后发生什么（前沿停滞并在顶面致密沉积？ε_new 自调？）；因此它是**动力学生长可行性判据**，输出为裕度
F − (1−ε_new) 与临界晶粒 d_c,crit = 5 D_eff(1−ε_new)/(β² ε_new (1−C_eq) k_r)，不是封壳事件。[V]：自洽参考解在 d_c < d_c,crit 时
带孔隙率在有限时间内趋零；这证实的是"稳态解不存在"，不是壳。

### 3.4 气相

∇·(ρ_D ∇X) = 0；j = −ρ_D ∇X·n。干多孔盐：ρ_D × factor（Knudsen，`effective_vapour_diffusivity(ε, r_p)`）。
**孤立湿结构的局部通量随 h 上升**：全覆盖平顶是精确一维解 j = ρ_D ΔX/(δ−h)；部分覆盖时顶面通量更高（侧向汇聚）且仍随 h 上升。
"屏蔽"是邻居与基底处 j 的**下降**，是另一个量。周期箱在 h_max > 箱宽后把领跑柱变成柱阵（plan/17 §2.2-12），S1–S3 限定 h ≤ 箱宽。

### 3.5 供液界限与有限液体储量的湿干过渡（第 8 条）[A]

不在 p_req > P_cth 时把蒸发置零或立即生成干壳。每个结构记液体储量 M_l,i = ρ Σ ε V（湿体素）：

```text
供液   Q_s,i = Q_demand,i                     若 p_req,i ≤ P_cth,i
       Q_s,i = Q(p_pore,i = −P_cth,i)         否则：孔口压力钉在阈值，网络在该吸力下能送多少送多少（Dirichlet 解）
储量   dM_l,i/dt = Q_s,i − j_wet,i A_wet,i − S_i        S_i：从退缩液体中就地析出的盐 C_eq ρ dV_drained
干层   d_dry,i = (M_l,i^0 − M_l,i)/(ρ ε A_i)   自顶向下退缩（[A]：活塞式，无角隅膜）
蒸发   j_wet 经干层串联：1/j ∝ (δ−h)/ρ_D + d_dry/(ρ_D·factor)
```
因此 E 连续下降到 j A_wet = Q_s 的新稳态（部分干的结构），时间常数 τ = M_l/(j A − Q_s)。Q_s > j A 时前沿回升（无滞后 [A]）。
盐账：析出 S_i 进 ledger 的内部沉淀通道；水账：M_l 的变化即储量项。两本账在过渡中逐步关闭。

### 3.6 单尺度固定微结构能否产生随时间的转变（第 4 条）

| 机制 | 在单尺度模型里 | 结论 |
|---|---|---|
| 动力学可行性 F ≥ 1−ε_new | F = F(Da*) 不含 j、h、t | 出生时已定，**无时间依赖** |
| 结构内黏性 + 重力供液失效 h* = (P_cth − ρ g H) k_s/(μ U_s) | k_s、P_cth 固定；U_s ~ 1.3 U_evap | 量级：d_sub 27.5 µm、ε_new 0.43、k_s 2e−14 m²（CK，仅作量级 [A]）、P_cth 3e5 Pa（r_pore ≈ 0.5 µm）给 h* ~ 10⁴ m；取致密化后 ε_final ≈ 0.23（F ≈ 0.74，Da* ≈ 8）、k_s ~ 2e−15 仍 ~ 3 m。与 Wijnhorst 2025"毛细—黏性竞争不限高"一致 [L]。**不在毫米尺度** |
| 气相几何反馈（h → δ 时 j 上升；邻居屏蔽） | 改变 v 与 U，不改 F | 改速率，不改类型 |
| 覆盖 / 合并 | 空间统计（S4） | 唯一能产生 θ、κ、E/E₀ 轨迹的机制 |
| 微结构随高度变化 | 后置的分级闭合 | 产生 d_c(n) < d_c,crit 的层序 [V]，但其闭合不确定性已量化为 1–2 层 |

**限制声明**：S1–S3 的单尺度模型预测"持续生长"或"出生即不可行"，不会出现随时间的局部封壳。不得为了得到壳而人为加状态。

## 4. S1–S3 最小模型与验证

### 4.1 S1：单孔 + 单个 Prat 结构（闭合形式，ε 不演化）

对象：D-10 等价单柱（n_side = 1，10 层 + 15 mm 集总段，H = 22 mm）；三维气相箱（周期侧边，δ 远场）；一个结构。
方程：§3.4 气相；网络 `network_step`（§6 后）；成核 C_pore ≥ C_sat，籽晶 m_seed 从孔内盐扣除；生长 §3.2 的 v 与 S_tot。
输出：t_nuc、h(t)、v、m_s 拆分（前沿 / 带内 / 孔内 / 缓冲）、j(t)、E/E₀、C_top*、Π、两本账。

验证：
1. 无结构、a_w = 1 的给定需求：t_sat = 1.917673 h（Stage-T 单柱）[V]；换 a_w(C) 反馈后记录新值并解释（a_w 降到 0.75 使 j 降）。
2. 固定 j 时 v、C_top* 与式 (29)(31) 偏差 ≤ 1e−3；m_s 总量 = C_eq/(1−C_eq) × 蒸发水量（≤ 1e−10）。
3. **气相基准**：(a) 全覆盖平顶：j = ρ_D ΔX/(δ−h) 精确，相对误差 ≤ 1e−6，j 随 h **上升**；(b) 半径 a ≪ 箱宽的单柱：顶面 j 高于 (a) 且随 h 上升；
   基底处 j 低于裸值（屏蔽）；(c) h 接近箱宽时报告周期像伪影的起点。
4. 籽晶：`salt_crystallised = salt_supplied + salt_nucleated + salt_interface_buffer` 成核前后成立。
5. D-50 对照：同算例 t_nuc、v 偏差 ≤ 0.5 %。

### 4.2 S2：单孔上的孔隙率演化、可行性与湿干过渡

在 S1 上加：§3.1 的 (1)(2)(4) 积分（自洽）；§3.3 的裕度与 d_c,crit；§3.5 的供液与储量模型；干顶 Knudsen。
输出：ε(z,t)、ε_final（预测）、裕度、Π(t)、d_dry(t)、E/E₀ 分解 R_gas / R_dry。

验证：
1. ε_final、h(t) 与分层参考解（自洽变体，dt ≤ 0.5 δ_C/v）一致 ≤ 1 %。
2. d_c 扫过 d_c,crit：可行 → 不可行；β 取 √2、2√2 时 d_c,crit ∝ β⁻² [V]。
3. 盐账：前沿 + 带内 + 孔内 + 缓冲 = 供给，≤ 1e−10；水账含 M_l 储量项。
4. 人为降低 P_cth：E 连续下降、τ 与 M_l/(jA − Q_s) 一致、回升可逆；无瞬时置零。

### 4.3 S3：两孔相互作用（第 7 条，几何审计后）

**几何事实**：`PoreLayer` 是周期方阵。n_side = 1 无横向喉道；n_side = 2 时周期像使每对相邻孔有两条平行喉道（4 孔环，不是两孔）；
`from_dgf` 只接受单柱。因此"任意 2×1 网络"目前不存在。

**设计（两级）**：
- **S3a（零代码改动，对称控制）**：n_side = 3 周期箱（2.1 mm），中心孔扰动（d_pore 或初始 j +5 %），其余 8 孔分两个对称类（4 边、4 角）。
  对称性是数学控制：无扰动时三类逐位相同；有扰动时边类与角类各自内部逐位相同（破缺即数值耦合错）。相互作用量 = 中心对边类。
- **S3b（一处代码改动）**：扩展 `PoreLayer.from_dgf` 接受多柱 2-D dgf（`n_surface > 1`，非周期），写两根 10 层柱、在指定深度用地下横向喉道相连。
  这是真正的两孔网络，横向边界非周期；气相箱仍周期，所以气相侧用两种箱：共用（两柱同箱）与独立（两柱各自箱）。

**2×2 因子**（S3a、S3b 都做）：

| | 共用气相场 | 独立气相场 |
|---|---|---|
| 地下横向喉道保留（D） | 完整 | 只有地下竞争 |
| 地下横向喉道去掉（B1） | 只有气相屏蔽 | 空对照 = 独立 S1 |

输出：t_nuc 差；v 比；屏蔽 j₂/j₁(h₁)；地下横向通量分记对流与扩散（Codex 复核 §2）；E/E₀；两本账。

验证：空对照格与独立 S1 逐位相同；对称类逐位相同；"只有屏蔽"格的 j 降幅与单独气相解一致；"只有地下"格的符号与 Stage-T（地下横向喉道延后首次饱和、降低表面方差 [V]）对照并解释；间距 ×2（S3b）时相互作用衰减。

## 6. 内核统一（第 10 条，先于一切新物理）

| | baseline-selfconsistent `pnm/transport.network_step`（2026-09-21） | Stage-T `pnm/conservative.conservative_step`（2026-10-26） |

| 生产使用 | `driver3d`、`pnm_column` | opt-in，Stage-T 50 例（s_out = 0） |
