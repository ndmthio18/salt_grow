# T1 Stage-T：结晶前基底水–盐输运（evaporation-wicking）执行记录与报告

**Regime：evaporation-wicking**：基底饱和、刚性，底部接盐库（固定 C0 = 0.25、压力基准），表面孔按**给定需求**失去纯水，盐留在网络里。
本阶段**不含**结晶、蒸气场、饱和度变量；所有结果只到第一个表面孔达到 C_sat 为止有物理意义，之后的数据标为"无沉淀反事实"。

基线：`7179312b388a37d2dc1901651904761aeff4c755`（分支 `codex/substrate-wicking-stage-t`，从 `codex/localized-nucleation-seed` 分出）。

## 0. 结论先行

| 问题 | 结果（实测） |
|---|---|
| 生产路径是否守恒？ | **否**。`solve_pressure` 没有孔储存项，`salt_step` 是非守恒的滞后密度形式。在本研究的结晶前瞬态里，盐账残差 = **+15.5 %（占网络增盐量）**，水账残差 = **+13.4 %（占蒸发水量）**。用同一把尺子量，残差**恰好等于** V·w·Δρ（盐）与 V·Δρ（液体），`tests/test_stage_t_transport.py` 钉住了这一点。浓度本身只偏 0.22–0.26 %（t_sat），B2–C 差值只偏 1.3 s |
| 守恒的实验路径 | 新增 **opt-in** `saltv2.pnm.conservative_step`：液体带储存项 V·Δρ/dt，盐写成守恒形式 Δ(Vρw)，两者用 ρⁿ⁺¹ 的 Picard 迭代耦合。全部 47 个守恒算例的相对残差 ≤ 5e-11（盐、水），单步残差 ≤ 2e-18 kg。生产路径一行未改；frodo 上全套测试：r1 的代码树 182 passed / 1 skipped，最终代码树（`ac1ddf66`）183 passed / 1 skipped（均含逐位回归参考） |
| 空对照 | 均匀需求、均匀孔：B1 = B2 = C = 单柱，t_sat = 1.917673 h，差 < 1e-12 h；C 的地下侧向流 / E = 2e-12 |
| B2 vs C（地下侧向喉道的作用） | **需求不均匀时**（stripe、hotspot），C 的首次饱和**更晚**：+162 s（+2.6 %）、+339 s（+6.8 %）。1 h 时表面浓度方差降到 B2 的 0.56 / 0.63。**孔径不均匀时**（cv = 0.25，均匀需求，5 个实现），C 的表面方差**全部更大**（×1.39–2.45），但 t_sat 差的符号不稳定（−161 … +551 s，5 个中 1 个 C 更早）。首个饱和孔在 B2 与 C 中都相同（5/5） |
| 时间步收敛 | 一阶，dt = 30 s 的 t_sat 误差 ≈ 7 s（Richardson），比 B2–C 差值小 13–240 倍（最小的差值是 cv25 seed 2 的 95 s）；B2–C 差值本身在 dt 30 → 15 s 时变化 < 0.6 s |
| 物理深度（E） | 深度 ≥ 7 mm 时 t_sat 与深度几乎无关（7 → 70 mm 变化 < 0.25 %）。3.5 mm 时盐库在扩散长度之内（√(D*t) ≈ 3.2 mm），t_sat 变为 2.14 / 2.61 h，B2–C 差 +1708 s |
| 横向域（D） | **5×5 对 B2–C 差值没有收敛**：固定局部需求场时，差值为 +339 s（5×5）→ +612 s（10×10）→ +689 s（20×20）；B2 在 10×10 已收敛（+0.24 %），C 仍在变（+1.5 %）。总量固定的 hotspot 为 +339 → +474 → +490 s |
| A（现行单层 + 集总盐库喉道） | 首次饱和比解析网络早约 5 倍（0.384 h 对 1.918 h；hotspot 0.316 h 对 1.383 h）。原因是深度方向没有储量（每柱少 50 倍），而喉道阻力反而是解析柱的 4.4 倍 |
| 毛细供液 | 压力解成功**不等于**供液可行。黏性压降只有 ≈ 7e-4 Pa；需求几乎全是静水头：G1（H = 35 mm）409 Pa，G2（H = L_s = 22 mm）257 Pa。表面孔口界限 2γ/r = 556 Pa，裕度 1.36 / 2.16；cv25 时最大孔给出 451 Pa，裕度 1.10；**70 mm 深时 817 Pa > 556 Pa（裕度 0.68），而求解器照常"供液"** |
| Stage-T 门 | **有条件通过**：守恒、空对照、配对、时间步收敛均在守恒路径上通过；有两个开放条件——横向域尺寸，以及需求闭合（给定需求 vs a_w 反馈）。**Stage-G（结晶/生长）没有启动** |

## 1. 审计：实际方程、单位、边界条件（基线代码）

| 环节 | 代码位置 | 实际形式 | 单位 / 边界 | 守恒性 |
|---|---|---|---|---|
| 网络 | `saltv2/pnm/network.py` `PoreLayer` | 立方孔 V = (2r)³；侧向 4 邻周期格；`n_layers > 1` 时向下复制、竖向喉道连接；**只有最底层**接盐库喉道（长 `Lt_res`）；z = 0 是表面，向下为负 | m、m³ | — |
| 导度 | `PoreLayer.conductances / diffusive` | 方喉 g = 0.5623·A²·G/(μL)，A = 4r_t²，G = 1/16；扩散 D·A/L，D = 1.54e-9 | m³/(Pa·s)、m³/s | — |
| 压力 | `pnm/flow.py` `solve_pressure` | Σ ρ^up g Δp = q_mass，盐库 p = 0；**准稳态，没有 V dρ/dt**；**没有重力** | Pa（黏性压力） | 液体质量只在 ρ 不随时间变时守恒 |
| 盐 | `pnm/transport.py` `salt_step` | V ρ(wⁿ)(wⁿ⁺¹ − wⁿ)/dt = Σ[Q ρ^up w^up + d ρ_face Δw]；盐库为固定 C_res 的 Dirichlet | kg、质量分数 | **非守恒**：V·w·Δρ 没有通量对应 |
| 蒸发 | 本研究：给定需求；生产：体素蒸气场或 `boundary_layer_evaporation` | 表面孔失去纯水 | kg/s | — |
| 水账 | — | **没有全局水存量账**（CLAUDE.md 已列为残留问题） | — | — |

**几何深度、储量、阻力是三件事**（`network_audit`，每个表面孔一柱，35 mm）：

| 表示 | 深度 | 每柱孔体积 | 有效孔隙率 | 每柱水力阻力 [Pa·s·m⁻³] | 每柱扩散阻力 [s·m⁻³] |
|---|---|---|---|---|---|
| A：单层 + 35 mm 集总喉道 | 35 mm | 1.575e−10 m³（只有表面孔） | 0.009 | 4.06e11 | 3.33e14 |
| B1/B2/C：50 层，dz = 0.7 mm | 35 mm | 7.873e−9 m³（50 倍） | 0.459 | 9.27e10 | 7.61e13 |

解析网络里阻力只在喉道（每根长 160 µm，50 根共 8 mm），储量只在孔体（540 µm 立方），所以同样 35 mm 深，A 的阻力是解析柱的 **4.4 倍**，储量却只有 **1/50**。改变层数（在 dz 固定时）改变的是物理深度，不是网格分辨率；孔网的离散尺度就是介质本身的孔尺度，**层数增加不是网格收敛**。本网络的柱扩散率 D* = d·dz/(εA) = 2.05e−9 m²/s，与 2014 连续模型的 ε^0.4·D_s ≈ 1.1e−9 不对应（README E1 §13.1 的已知结论，几何推论，不标定）。柱 Pe = n·ln(1 + Q/d) = 0.49（35 mm，2014 Table 1 通量）。

## 2. 设计

### 2.1 网络（`saltv2/cases/stage_t_wicking.py`）

- **C**：`PoreLayer(n_side=5, pore_radius=270 µm, n_layers=50, dz=0.7 mm)`，盐库喉道长度 = 竖向喉道长度（dz − 2r），即盐库是底层下方再一个 dz 的节点；表面孔中心到盐库节点 = 50 × 0.7 = 35 mm（= 2014 珠柱高，`vtp2014_column.L_COLUMN`）。
- **B2**：C 经 `pnm.drop_throats` 去掉**地下侧向喉道**（2450 根）。孔、坐标、体积、初值、竖向喉道（1225）、盐库喉道、表面侧向喉道（50）、需求与 C **逐位相同**（`test_B2_and_C_differ_only_in_the_subsurface_lateral_throats`）。
- **B1**：再去掉表面侧向喉道（独立柱），对照。
- **A**：生产表示，单层 25 孔 + 每孔一根 35 mm 集总喉道 + 表面侧向喉道。
- 孔径：均匀 r = 270 µm（dgf 中位值，去掉 ±10 µm 抽样，空对照因此严格）；异质算例 `cv = 0.25`（`PoreLayer` 自带的对数正态，喉道 = 0.485·min(r_a, r_b)），seed 1–5。

### 2.2 需求（每孔水损失，kg/s，所有图案总量相同）

平均 J = 1.5854e−5 kg m⁻² s⁻¹ × 孔距²（[M] 2014 Table 1，与 `cases/pnm_column` 同值）。
`uniform`；`stripe`：1 + 0.5 cos(2πx/L_box)；`hotspot`：中心孔 4 倍，其余 (25 − 4)/24 倍 [A，测试用，不是标定值]；
`hotspot_fixedbg`：保持 5×5 的局部需求场（热点 4J，其余 0.875J）到任意大的盒子，只改变热点周期像的间距（D 算例的去混淆版本；5×5 时与 `hotspot` 逐位相同，有测试）。

### 2.3 数值与输出

后向 Euler，dt = 30 s（细化 60 / 15 / 7.5 s）；Picard 收敛判据 max|Δw| ≤ 1e−13，不收敛就抛异常（平均 4–5 次迭代）。
t_sat 用相邻两步线性插值。运行到全部表面孔越过 C_sat 或 24 h（截尾）；**没有算例被截尾**。
快照：0.25、0.5、1、1.5 h（共同时刻，用于 B2/C 分布比较）、首次饱和、结束。
诊断（`pnm.step_residuals`，两条路径用同一把尺子）：每步液体 / 盐 / 水的存量变化减通量积分；累积蒸发水、盐库进液、进盐。

### 2.4 毛细界限与重力假设（只做事后比较，不耦合）

p_req,i = −p_i（黏性，求解所得）+ g∫₀ᴴρ dz（沿该孔所在柱的实际密度）。
**G1**：盐库液面在盐库节点，H = 网络深度（35 mm）；**G2**：H = L_s = 22 mm（2014 珠面到液面的高差）。
界限（Young–Laplace，完全润湿，内切半径，忽略方管角流 / MSP 形状因子这一 O(1) 修正）：表面孔口 P_open = 2γ/r（超过时弯月面退入孔体，即**去饱和，模型不能表示**），最细喉道 P_throat = 2γ/r_t。
**重力不在流动求解里**：密度驱动的盐分下沉不稳定（重盐水在轻盐水之上）完全缺失。**本模型不表示饱和度变化或弯月面移动**；裕度 < 1 只说明"这个解在物理上不成立"，不说明会发生什么。

## 4. 结果

（数字来自 `results/combined/pairs.md`；dt = 30 s，守恒路径，除非另注。）

### 4.1 空对照与配对

均匀需求、均匀孔：B1、B2、C、单柱的 t_sat 全部为 1.917673 h（差 < 1e−12 h），25/25 个表面孔同时越过；C 的地下侧向流 / E = 1.9e−12。
B2 与 C 的配对由 `drop_throats` 保证，并由测试核对。

### 4.2 守恒

| 路径 | 相对盐残差（占增盐） | 相对水残差（占蒸发水） | 单步最大盐残差 |
|---|---|---|---|
| 守恒（全部 47 例） | ≤ 5.0e−11（最大的是 dt 7.5 与 20×20 两例，步数或孔数多） | ≤ 4.4e−11 | ≤ 1.6e−18 kg |
| 生产（B2/C hotspot，C uniform） | **+1.55e−1** | **+1.34e−1** | 2.7e−10 kg |

生产路径的盐残差 = Σ V·w·Δρ，液体残差 = Σ V·Δρ（测试到相对 1e−6）。w·(dρ/dw)/ρ ≈ 0.18（w = 0.25），所以增盐中约 15 % 没有通量来源；
同理，结晶前瞬态里盐水变密所储存的液体质量约为蒸发量的 13–18 %，在生产路径里没有从盐库吸进来。
两者在浓度方程里几乎相消（二阶），所以浓度和 t_sat 只偏 −0.22 %（B2 hotspot −11 s）、−0.23 %（C hotspot −12 s）、−0.26 %（uniform −18 s），配对差值 338.0 s 对 339.3 s。
**结论：生产路径可用于浓度和时间，但不能用来做水 / 盐账。生产行为没有改动，也没有重定基线。**

| 60 | 1.38550 | 1.47970 | +339.1 |

| 50 | 35 mm | 1.38348 | 1.47773 | +339.3 | 409 | 1.36 |
| 100 | 70 mm | 1.38344 | 1.47773 | +339.5 | 817 | **0.68** |

富集只发生在表面以下几个扩散长度内（√(D*·1.4 h) ≈ 3.2 mm ≈ 4.6 层），所以深度 ≥ 7 mm 后 t_sat 不再变。3.5 mm 时盐库离表面太近，盐被扩散回盐库，富集变慢，B2–C 差反而放大。
**需求压力随深度线性增长（全是静水头），70 mm 时超过孔口界限，但压力解照常成功**——这正是"求解成功 ≠ 供液可行"的一个实例。

### 4.6 A 与 B1 对照

| 算例 | t_sat [h] | 对应解析网络 |
|---|---|---|
| A uniform | 0.384 | 1.918（快 5.0 倍） |
| A hotspot | 0.316 | 1.383（快 4.4 倍） |
| B1 hotspot | 0.183 | B2 1.383（快 7.6 倍） |

A 的表面孔没有地下储量，且集总喉道的扩散导度很小（Q/d_res = 2.2，而解析柱每根喉道是 0.0099），所以表面孔浓度一开始就被推向很高的稳态比值。A 的表面侧向喉道导度是集总喉道的 200 倍以上，热点孔 75 % 的水从侧向来（与 B2 相似）。
**A 不能用来给出 t_sat 的量级**（偏早约 5 倍）；这与 CLAUDE.md 中"集总喉道比解析柱阻力大 2.19 倍（22 mm）"是同一类问题：储量与阻力同时失真。

### 4.7 横向域（D：孔尺度与深度固定）

| 需求 | n | t_sat B2 [h] | t_sat C [h] | C − B2 | 1 h 方差 B2 / C |
|---|---|---|---|---|---|
| hotspot / hotspot_fixedbg | 5 | 1.38348 | 1.47773 | +339.3 s（+6.8 %） | 2.88e−7 / 1.80e−7 |
| hotspot（总量固定，背景 0.97） | 10 | 1.27717 | 1.40896 | +474.4 s（+10.3 %） | 1.49e−7 / 8.00e−8 |
| hotspot_fixedbg（局部场固定） | 10 | 1.49740 | 1.66736 | +611.8 s（+11.4 %） | 1.57e−7 / 8.47e−8 |
| hotspot（背景 0.99） | 20 | 1.23404 | 1.37018 | +490.1 s（+11.0 %） | 5.11e−8 / 2.96e−8 |
| hotspot_fixedbg | 20 | 1.50096 | 1.69223 | +688.6 s（+12.7 %） | 5.47e−8 / 3.17e−8 |

`hotspot` 在不同 n 下的背景需求不同（0.875 → 0.97 → 0.99），t_sat 的变化混有这一效应；`hotspot_fixedbg` 只改变热点周期像的间距。
两种设定下，B2–C 差值都随横向域增大而增大，**所以 5×5 不是这一观测量的横向收敛域**。
局部场固定时：B2 的 t_sat 在 10×10 已收敛（1.4974 → 1.5010 h，+0.24 %），C 还在变（1.6674 → 1.6922 h，+1.5 %），差值 +612 → +689 s（+13 %）。
总量固定时，差值 +474 → +490 s（+3 %）。一种解释（**未验证**）：在 C 里热点能从越来越大的地下面积补水，这个面积在 20×20（14 mm）时还没有饱和。
20×20 的 C 每例需要 1.7–2.2 h（20 000 孔，单步约 20–30 s，SuperLU 直接解）。

## 5. 局限（照实说明，不隐藏）

1. **需求是给定的**：每个表面孔的水损失与其浓度（a_w）和孔口面积无关。真实蒸发随表面浓度升高而下降，也随孔口面积变化；这会改变热点与孔径异质性两组结论的量级，cv25 组的符号尤其可能改变。
2. **饱和、刚性、无重力的网络**：没有去饱和、弯月面退缩、干涸或回湿；毛细界限与静水头只做事后比较（G1 / G2 两种液面假设）；密度驱动的盐分下沉不稳定完全缺失（2026 Na-MRI wicking 实验指出它可能重要）。
3. **网络几何**：QSPNM 的 540 µm 立方孔模板，均匀孔距 0.7 mm；D* 比 2014 连续值大约 1.8 倍（已知，几何推论）。"热点 4 倍"和"cv 0.25"是测试用的强迫 / 异质性，不是标定值。
4. **单一网络尺度**：没有做孔尺度 λ 扫描；毛细裕度随孔径反比变化，换成 2014 细珠（5–125 µm）时数值完全不同。
5. **生产路径的非守恒**是基线代码的已知性质；本研究只在 opt-in 路径里修正。生产是否切换会改变全部运行记录，属于另一个决定。
6. **5×5 横向域不收敛**，20×20 时 C 仍差约 1.5 %（§4.7）；cv25 只有 5 个实现，且只在 5×5 上做过。
7. 对话中提到的任务书附件没有取到；本设计依据对话中可见的最后一条消息与本任务说明。

## 6. Stage-T 门判定

| 判据 | 状态 |
|---|---|
| 盐 / 水守恒到舍入（实验路径） | **通过**（≤ 5e−11 相对） |
| 生产路径守恒 | **不通过**（15.5 % / 13.4 %）；已隔离为 opt-in 实验路径，生产未改，失败如实记录并由测试钉住 |
| 空对照 B2 = C = 单柱 | **通过** |
| 配对只差地下侧向喉道 | **通过**（测试） |
| 时间步收敛足以解释 B2–C 差值 | **通过**（误差 7 s，差值 ≥ 95 s；差值对 dt 不敏感） |
| 物理深度敏感性 | 已量化：≥ 7 mm 后 t_sat 不变（物理结论，不是数值收敛） |
| 横向域 | **开放**：5×5 不收敛；20×20 时 B2 已收敛、C 还差约 1.5 %（局部场固定），见 §4.7 |
| 毛细供液可行性 | 只做事后比较；35 mm / G1 下裕度 1.36（cv25 为 1.10），70 mm 下 < 1。**模型本身不能判断供液失败** |
| 需求闭合 | **开放**：只测了给定需求 |

**总判定：Stage-T 有条件通过。** 进入 Stage-G 前至少要：(a) 用守恒路径；(b) 确定 B2–C 差值的横向收敛域（20×20 还差约 1.5 %），或者明确接受有限尺寸偏差（5×5 把差值低估约一半）；(c) 把给定需求换成 a_w 反馈的蒸发闭合，重复 B2–C 配对。**本次没有启动任何结晶 / 形貌计算。**

## 7. 后续任务（尚未做）与科学假设（未验证）

**任务**
1. 横向收敛：加 40×40 的 `hotspot_fixedbg`（只跑 B2 / C 两例；深度可截到 10 层，§4.5 表明 7 mm 以下对 t_sat 无影响；需要迭代求解器或者更好的预条件，直接解在 20×20 已经要 2 h）。
2. 需求闭合：`boundary_layer_evaporation`（a_w(C)、孔口面积）驱动下重复 B2/C × {hotspot, cv25}；再用体素蒸气场。
3. **标定的降阶边界**：§4.5 表明 7 mm 以下对 t_sat 几乎没有影响。可以只保留近表面 N 层三维网络，底部换成一维柱或标定的 Robin 边界，用本研究的 C（50 层）作参考解检验。
4. 是否把守恒路径接进 `driver3d`（会改变运行记录，应与 CLAUDE.md 列出的其他残留一起做一次生产重跑）。
5. 重力耦合与去饱和模型（drying 阶段的前置条件）。

**假设（本研究的数据提示、但没有证明）**
- H1：地下侧向连通性会平滑由**蒸发强迫**造成的表面浓度不均（方差 ×0.56–0.63），却会放大由**孔径异质性**造成的不均（×1.39–2.45）。前者可以用"热点的补水来自较淡的深层"来解释；后者的机制没有分析。
- H2：在本网络尺度和通量下，富集深度约等于扩散长度，所以离表面几毫米以外的基底可以用降阶边界代替。
- H3：首个成核位置（t_sat 最早的孔）在 B2 与 C 中相同，而且由孔径决定；地下侧向连通改变的是时间和后续的空间分布，不是第一个位置。需要在 a_w 反馈的蒸发下复核。
