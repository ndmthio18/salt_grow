# 子计划总览

`../v2_建模方案.md` 是总方案；本目录把它拆成 8 个可独立执行、独立验收的子计划。
拆分原则：**每个子计划只加入一个物理机制或一层数值能力，加入前说明依据，加入后用一个不依赖后续步骤的检验把它钉住。**
前一个子计划的检验不通过，后一个不开工。

## 依赖链

```
S1 气相蒸发 ──> S2 平层生长律 ──> S3 二维几何演化（无供液限制）
                                       │
                                       v
                          S4 盐内供液 + 干涸门控（重力 + 黏性）
                                       │
                                       v
                          S5 干盐蒸汽阻力 + Kelvin + crust 分支
                                       │
                                       v
                          S6 分级 patchy 分支 + 敏感性矩阵
                                       │
                                       v
                          S7 实验对比 ──> S8 PNM 接口冻结
```

S1–S3 只用已在 `../../prat2026` 与 `../../../salt_grow` 验证过的物理，风险在数值；
S4–S6 各加入一个新机制，风险在物理与参数；S7 是证据汇总；S8 不加物理。

## 每个子计划的固定结构

1. **目的**：这一步要让模型多会什么。
2. **依据**：物理模型（来源论文与式号）、数值方法、参数（M 测量 / L 文献 / A 假设 / B 反标定 / V 本项目验证）。
3. **前置**：依赖的子计划与其验收项。
4. **实现**：模块、主要函数、数据流。
5. **验收**：测试 → 判据 → 判据的依据。全部写进 `tests/`，可一条命令复跑。
6. **完成后可以声称 / 仍不能声称**：把证据边界写死，避免后文越权。
7. **陷阱**：已知会出错的地方。
8. **工作量**：人日粗估。

## Regime 声明（每个子计划头部必须重复）

V1 全部子计划的 regime 是 **evaporation-wicking**，在模型里的操作定义：
(1) 基底始终饱和，只作 z = 0 边界；(2) 底部液压 p_l,0 恒定（储液池深 L_s）；(3) 基底浓度 C_0 = C_eq；(4) 盐量无限，生长停止只能由门控引起；结构到达管口 z = δ 时模型停止，因为几何描述失效（管口开口、无盖板），不是生长停止。
drying 数据（Ben Amara 2025、Eloukabi 2013、Piotrowski 2020、Wijnhorst 2025 砂岩）只能在"基底仍饱和、盐量未成限制"的早期段与模型比，判定规则见 `09` §3。
drying 扩展（V2）改的是 (1)–(4)：p_l,0(t)、C_0(t)、有限盐量、基底域；盐域方程不变。

## 2026-09-02 的一处修正（影响 S4、S6）

供液上限必须同时含重力项与黏性项：H_lim = P_cth/(ρ_l g + μU/k_s)。patchy 由重力项控制（米量级），crust 由黏性项控制（毫米）。
旧代码 `growth_laws.capillary_rise_limit_decoupled` 只有黏性项，`salt_lattice.solve_pressure` 只解黏性压力、重力在门控里单独加；
`saltv2` 直接解总吸力场，一维参考解自己写。
