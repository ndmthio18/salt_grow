# S1 气相蒸发求解器

**Regime：evaporation-wicking。** 本步无液相，regime 只体现在默认几何与 RH 取自 Ben Amara 2025（drying 实验的几何，不是其液相条件）。

## 1. 目的

在给定几何（GAS / 湿面 / 干盐体素）上求稳态蒸汽场，得到每个湿面的局部蒸发通量 j。这是闭环里"蒸发"一环，之后所有步骤都从它取 j。

## 2. 依据

- 物理：准稳态、稀释极限、纯扩散，∇·(ρ_g D_eff ∇X_v) = 0，湿面 X_v = X_ve，顶 X_v = X_v∞（F§2，2014 式 6.1–6.4）。
  实验几何：样品管顶部开口于封闭箱，δ 是珠面到管口的凹陷深度，**不是盖板**（2014 §2、Ben Amara §2.1）。管口外的扩散阻力（圆盘源约 πr_w/4，2014 的 38 mm 管约 15 mm，与 δ 同量级）与自由对流（2014 Table 1 的 J_exp/J_num = 1.41/1.55/1.67 对 δ = 2.5/7.5/15 mm，[V] `table1_2014_check.py`）都不解，折成 δ_eff = δ + 等效长度，在顶边强加 X_v∞。
- 数值：有限体积，面扩散率调和平均，Dirichlet 半格系数 2（[V] efflorescence3d/vapor.py），`scipy.sparse.linalg.spsolve`。
- 参数：全部 L（总览"全局约定"）。本步 D_eff 只有 GAS 一种值；干盐的 D_eff 在 S5 加入，但接口现在就留出（按体素的 D_eff 场）。

## 3. 前置

无。

## 4. 实现

- `saltv2/grid.py`：`Grid(shape, a)`，`shape` 为 (nx, nz) 或 (nx, ny, nz)，最后一轴为竖直；状态数组 `state`；周期邻接用 `np.roll` 沿水平轴；界面识别 `wet_faces()` 返回 (体素索引, 轴, 方向)。全部函数对 ndim 2/3 同一实现（E 修订）。
- `saltv2/fv.py`：`assemble_laplace(D_field, dirichlet_mask, dirichlet_value, top_value)` → 稀疏矩阵与右端；`solve()`。
  这个组装器 S4 的 Darcy 复用（换 D_field 为 k_s/μ，换边界）。
- `saltv2/vapor.py`：`solve_vapor(grid, props)` → `X_v` 场；`face_flux(X_v)` → 每个湿面的 j = −ρ_g D_eff ∇X_v·n；`J_total()`、`J_ref()`（无盐平面的总通量）。
- 输入：`state`、`D_eff` 场、X_ve、X_v∞、δ。输出：X_v、j（按面）、J_tot。
- 默认算例几何取 Ben Amara 2025：δ = 15 mm、RH 7 %、21 °C（`09_BenAmara2025_在子计划中的用法.md` §1）。

## 5. 验收（`tests/test_S1_vapor.py`）

| 测试 | 判据 | 依据 |
|---|---|---|
| 平整湿基底、无盐 | j = ρ_g D_v (X_ve − X_v∞)/δ，相对误差 <1e−10；δ=15 mm 给 3.59e−5、δ=2.5 mm 给 2.15e−4 kg m⁻² s⁻¹ | 一维解析 |
| 网格加密 a → a/2 → a/4 | 一个方形盐块上的 J_tot 二阶收敛 | FV 二阶 |
| 周期性 | 盐块平移 n 格，X_v 场同步平移到机器精度 | 对称 |
| 半格 Dirichlet | 盐块顶面 j 与"盐块换成 Dirichlet 边界"的解析板问题一致 | efflorescence3d 同一实现 |
| 2014 Table 1 | 用一个管口外等效长度（R_ext 常数）复现 J(δ) 三个值，得到 δ_eff(δ) | [V] `table1_2014_check.py` |
| 3D 冒烟 | 同一平面算例在 (nx, ny, nz) 上给同一解析 j；方块盐在 3D 的 J_tot 与 efflorescence3d `VaporSolver` 一致 <1e−8 | E 修订；[V] efflorescence3d |

## 6. 完成后

可以声称：任何体素几何的稳态扩散蒸发场与局部通量正确到离散精度。
不能声称：任何关于盐生长或蒸发反馈的结论；对流增强只能以 δ_eff 形式出现。

## 7. 陷阱

- 盐块内部被包住的气袋是无通量的封闭子域，矩阵奇异；组装前把与顶边界不连通的 GAS 体素剔除（BFS）。
- J_ref 定义为同一网格、同一 δ_eff 下无盐平面的值；E 的所有后续定义都以它为分母。
- 结构逼近 z = δ（管口）时，周期条带 + 顶边 Dirichlet 不再代表真实几何（管壁到此为止，盐可伸出管口向箱体侧向扩散）；h_max ≥ δ − 2a 停止并在报告里写"到达几何有效上限"。
