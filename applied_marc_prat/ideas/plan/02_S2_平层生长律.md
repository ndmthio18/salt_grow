# S2 局部生长律与平层推进

**Regime：evaporation-wicking。** 结构内 C ≈ C_eq、底部持续供液（Prat 2026 的局部律本身 regime 无关）。实验时间原点取首次结晶，因为 drying 实验有浓缩期而 wicking 模型从 C_eq 起算。

## 1. 目的

把 S1 的 j 变成界面法向速度 V_n 与供液需求 U_dem，并建立事件步填充规则。用一维平层把实现钉到 `prat2026/core.py`。

## 2. 依据

- 物理：V_n = G F(Da*) j，G = C_eq/[ρ_cr(1−ε_s)(1−C_eq)]，F = √Da*/(1+√Da*)（F§3，Prat 2026 式 32、36）；
  U_dem = j/ρ_l + [ε_s + (ρ_cr/ρ_l)(1−ε_s)] V_n（F§4，式 33，含填孔项）。
  Da* 由 d_sub 经 a_v = 5(1−ε_s)/d_c、d_c = 0.14 d_sub 给出（`core.Da_star`）。
- 数值：确定性填充，界面格容量 V_max = (1−ε_s)a²，Δt = min (1−φ)V_max/V̇（F§8，[V] salt_deterministic）。
- 参数：k_r、D_s、E_a、β、C_eq、ρ_cr 全部来自 `prat2026/params.py`（L，含出处）；ε_s = 0.43（M，Dai）；ρ_l = 1200（B）。
  已知：ρ 与 β 是反推值，对 dh/dt 影响 <1 %（CLAUDE.md 陷阱节）。

## 3. 前置

S1 全部通过。

## 4. 实现

- `saltv2/growth.py`：`normal_velocity(j, eps_s, d_sub)` 直接调用 `prat2026.core.growth_rate`（不复制公式）；`liquid_demand(j, V_n, eps_s)`。
- `saltv2/advance.py`：`interface_voxels()`、`deposition_rate(V_n, wet_length)`、`event_step(tol)`：算 Δt = min (1−φ)V_max/V̇，推进 φ，把填充度 ≥ 1−tol 的格同时翻转为 `SALT_WET`，溢出量按 efflorescence3d `redistribute_overflow` 的思路分给相邻界面格（G 修订；tol 是数值参数，默认 0.05）；调用 birth 赋值钩子（S2 里钩子只写常量 ε_s）。
- `saltv2/ledger.py`：累计沉积盐质量、抽液体积、∫j dt；返回相对残差。
- `saltv2/model.py`：`SaltModel.run(n_steps)`，此时只装 S1+S2。

## 5. 验收（`tests/test_S2_growth.py`）

| 测试 | 判据 | 依据 |
|---|---|---|
| 整行盐层平推（无侧向） | 层高随时间的斜率 = `core.growth_rate(j, d_sub)`，相对误差 <1e−12 | F§12 第 1 项 |
| U_dem | 与 `core.U_over_Uevap × j/ρ_l` 一致到 1e−12 | 式 33 |
| 守恒 | 沉积盐质量 = ∫G F j dt、抽液 = ∫U_dem dt，相对残差 <1e−10 | F§12 第 2 项 |
| 事件步 | 单格填满时间 = (1−ε_s)a/V_n；两格不同 j 时先满者先翻 | F§8 |
| d_sub 扫描 | dh/dt 对 d_sub 的比值 = F(Da*) 的比值（25/90/580 µm） | Prat 2026 Fig 7 |
| tol → 0 | tol = 0.05 与 tol = 0 的平层高度差 <tol，守恒残差不变 | G 修订 |
| 3D 冒烟 | 平层在 3D 网格上推进，dh/dt 同 2D 到 1e−12 | E 修订 |

不能声称：任何形貌；任何 d_sub 对形貌的作用（[V] 均匀 F 只改时钟）。

## 7. 陷阱

- `core.growth_rate` 的 j 单位是 kg m⁻² s⁻¹，V_n 是 m/s；填充用固相体积 (1−ε_s)ℓV_n，不要再乘一次 (1−ε_s)。
- ρ_cr 在 salt_lattice 是 2160、prat2026 是 2170，统一用 2170 并在 params 注明。
