# S5 干盐蒸汽阻力、Kelvin 效应与 crust 分支

**Regime：evaporation-wicking。** 内部湿前沿的液体由储液池经湿盐补给（B 修订）；沉积密化机制本身 regime 无关，但在 drying 里供液终会中断而 V1 不会。14× 标定靶来自 2014 的 wicking 结壳实验（Fig 23），Ben Amara 引用同一数字。

## 1. 目的

让干涸的盐不再是零通量屏障，而是低扩散率的多孔层；加入湿前沿的 Kelvin 降活度；**给内部湿前沿补上供液与沉积密化（B 修订）**；给出 `NANOPOROUS_CRUST` 的常量 birth 规则。
完成后模型能给出 crust 的蒸发降幅 E(t)、壳厚平台与平台后的缓慢增厚。

## 2. 依据

- 物理：干盐体素 D_eff = D_v ε_s^1.5 φ_o（I§3.2 [A]，ε^1.5 是孔隙率-曲折度，φ_o 表面开孔分数取自 2014 §6.3 的稀疏开孔图景）；
  湿/干交界面 X_v = a_w a_w,K X_v,sat，a_w,K = exp[−2γcosθ M_v/(ρ_l R T r_p)]（F§2，2014 式 6.9 量纲修正版；特征长度 1.1 nm）。
  K§6、K§8 结论 2：14× 降幅不能只靠 Kelvin（需 r_p < 1 nm），需要总开度 D_eff/D_v ≈ 5e−3。
- 参数（crust 常量，I§3.2）：ε_s = 0.25（M，Licsandru 压汞）；r_p = 3.5 nm（M，Licsandru Kelvin 反推）；P_cth = 2γcosθ/r_p ≈ 4e7 Pa（推导）；
  k_s = 2.5e−22 m²（B，壳厚 = H* 反推，扫 1e−22–1e−21）；φ_o **B，本步唯一标定量**，锚 2014 Fig 23 / Ben Amara 的 14×。
- **内部湿前沿（B 修订，F§5.1）**：前沿面蒸发 j_front > 0 时，液相边界 q·n = (j_front/ρ_l)[1 + F C_eq/(1−C_eq)]，与 Prat 式 33 同一推导但无移动界面的填孔项；
  局部析盐固相速率 Ṡ = F j_front C_eq/[(1−C_eq)ρ_cr]，沉入前沿湿体素：dε_s/dt = −Ṡ/a；ε_s 降到 ε_s,min = 0.05（[A]）该体素转 SALT_DRY、前沿后退一格。
  D_eff 随该体素的 ε_s^1.5 下降，故 E(t) 在平台后继续缓慢下降——这就是 Ben Amara 的"壳变干变密"，不需要 φ_o(t)。V1 假设 [A]：密化只改 ε_s，不改 k_s 与 r_p。
- 数值：D_eff 场进 S1 的组装器；Kelvin 只改湿/干相邻面上的 Dirichlet 值；ε_s 成为前沿体素的时变量（数组不变，只是允许写）。

## 6. 完成后

可以声称：crust 的蒸发降幅由"壳厚 × 有效开度 × Kelvin"三者给出，其中开度是标定量、壳厚是模型输出、Kelvin 是可开关的物理项；
平台后 E(t) 的继续下降与缓慢增厚由前沿沉积密化给出，不含新参数（ε_s,min 除外，敏感性要报）。
壳厚平台 ≈ H_lim 是一致性，不是验证（k_s 由它反推）；crust 分支独立的预测是动力学：到达平台的时间、η(t)、E(t) 形状。
不能声称：E = 1/14 是验证（它是标定靶）；φ_o 的物理来源；crust 微结构为何形成。

## 7. 陷阱

- Kelvin 半径 r_p 在密化后应更小（a_K 更低），V1 保持常数并说明（审查 H3）。
- I§3.2 原写"φ_o 预期 ~5e−3"，那是总开度 D_eff/D_v；按定义 D_eff/D_v = ε^1.5 φ_o，φ_o 本身约 4e−2。以本文为准（已同步修正 I§3.2）。
- 壳厚平台的 H_lim 要用降幅后的 j（≈7e−6），不是无盐时的 j；两者差 14× 就是平台差 14×。
- 干盐体素与 GAS 体素之间 D_eff 相差 200×，调和平均使面导度几乎等于干盐侧值，网格加密时收敛慢；用一维串联解析监控。
