# 15 干化状态 SALT_DRY：把"供液判据"变成"干化过程"

**Regime：evaporation-wicking**（V1；基底饱和、盐库无限）。写于 2026-09-03，起因见 `runs/E1_pre/README.md` §7.3：
封盖后模型 E 停在 1.1–1.5，实验降到 0.05–0.3，差别全部来自"冻结的顶部仍按湿面蒸发"。

## 1. 现状与问题

预实验里供液检查失败只做一件事：z ≥ h_freeze 的面 V_n = 0。这些面在蒸气场里仍是 X = X_salt 的 Dirichlet 面，仍蒸发、仍计入抽液需求。
物理上顶部失连后液体退走、孔变干：干盐不蒸发，蒸发面退到盐结构内部的湿/干前沿，前沿以上的干层成为蒸气扩散阻力。
2014 §6.3 的"结壳后蒸发降 14 倍而不归零"、Ben Amara #1 的 14×、本项目 Fig 23 数字化的 0.05–0.3，都是这个阻力的表现。

## 2. 物理模型

### 2.1 状态与转换
体素状态：GAS、SALT_WET、SALT_DRY、SALT_SEALED（`saltv2/grid.py`）。

> **2026-09-04 语义冻结（plan/17 §3.1，本文以此为准）**：`SALT_DRY` 的正式语义是 `SALT_DRY_OPEN`
> ——**可透汽**（以 $D_{\rm eff}$ 参与气相解）、不供液、不生长；孔隙被前沿析盐填满
> （$\varepsilon_s\le\varepsilon_{s,\min}$）后转入新状态 `SALT_SEALED`，对蒸汽与液体**都是墙**。
> 本文以下正文写于该冻结之前，凡把 `SALT_DRY` 当作"封闭壳"之处一律以此为准。
> 回湿在首版被禁止（不可逆状态机）：`runs/E1_pre/pre_experiment_vapor.run` 的默认
> `allow_rewet=False`，本文 §3 的 χ / τ_dry 分支仅供复现旧结果。
- **干化**：簇的供液检查失败时，该簇 z ≥ h_freeze 的 SALT_WET 体素 → SALT_DRY。h_freeze 由 need(h) = P_c(a_n) 二分给出（plan/13 叠层）。
- **回湿**：当 need 回落，使 h_freeze,new·(1 − χ) 高于某些干体素时，它们 → SALT_WET。χ 是滞后系数（A，取 0.2；RR26 的湿干滞后、W24 的湿干循环支持"有滞后"，数值未测）。
- 干化不改变几何：体素仍是盐；只改变它在蒸气场里的角色。

### 2.2 干盐在蒸气场里的角色
干盐是**多孔扩散介质**，不是源也不是墙：
$$D_\mathrm{eff}(z) = \varepsilon_s^{1.5}\Big[\frac{1}{D_v} + \frac{1}{D_K(a(z))}\Big]^{-1},\qquad D_K = \frac{a}{3}\sqrt{\frac{8RT}{\pi M_w}}$$
- ε_s^{1.5} = ε_s/τ，τ ≈ ε_s^{−0.5}（knowledge L：堆积体曲折度）。
- Knudsen 项按 Bosanquet 串联（L，标准气体动理论）。a(z) 是该高度所在分层的孔径：层 n 覆盖 [h_cum, h_cum + h_n)，a_n = a_1/2^{n−1}（plan/13 规则，与供液检查用同一套 a_n，无新参数）。
  λ = 32 的顶层 a ≈ 37 nm → D_K ≈ 7e−6 m²/s，D_eff ≈ 0.065 D_v；1.1 mm 干层 ≈ 17 mm 等效空气层。
- 湿/干前沿：SALT_WET 体素与相邻 SALT_DRY 体素之间的面是 X = X_salt 的 Dirichlet 面，蒸发通量 j = 2ρ_g D_eff (X_salt − X_dry)/a。

### 2.3 前沿处的结晶
前沿蒸发带来的盐在前沿析出，但前沿两侧都已是盐体素，不能再"长"。V1 处理：把这部分盐记入台账 m_front（kg），换算为干层平均孔隙率减少 Δε_s（`v2_model_formulation.md` §5.1 的 dε_s/dt），**不改几何、暂不反馈到 D_eff 或 k_n**（后续版本可反馈：致密化 → D_eff 降 → 正反馈，这是 Licsandru 壳 ε_s 0.25 vs patchy 0.43 的可能来源）。

### 2.4 反馈回路（新出现的物理）
顶部干化 → 前沿通量经干层衰减 → 簇抽液 U 下降 → need 下降 → h_freeze 上移 → 部分回湿 → 通量回升 → …
这是 RR26 的松弛振荡器结构；滞后 χ 决定它是收敛到一个稳态前沿还是持续湿干循环（W24 观察到循环）。**这是模型可能给出、且有文献可对的新预测**。

## 3. 实现（预实验脚本先做原型，验证后提入 saltv2）

## 4. 验收

1. 测试 (i)–(iii) 通过。
2. λ = 16、32（2014 条件）：封盖后 E 下降而非停滞；给出前沿高度与干层厚度随时间。
3. 与 Fig 23 对比：5–50 µm 实验 E → 0.05–0.12；50–62 µm 降到 0.28 后回升。模型若给出同量级的下降即达标；回升需要壳上再成核，不在本步范围。
4. 湿干循环若出现，记录周期与幅度，与 W24 定性对照。

## 5. 之后可以声称 / 不能声称

- 可以：封盖后的蒸发下降是干层扩散阻力（含 Knudsen）的结果；下降幅度对分层孔径敏感。
- 不能：绝对 E 值（D_eff 的 ε^1.5 与 Bosanquet 均为 L 级闭合，未对盐层测过；a_n 来自 c_k 同源的分层规则）；壳上再成核与第三阶段。

## 7. 原型实现记录（2026-09-03）

- `saltv2/vapor.py`：`solve_vapor(porous=(mask, factor))` 已加，测试 `test_porous_cap_is_series_resistance_and_default_unchanged` 通过（26/26）。
- `runs/E1_pre/pre_experiment_vapor.py`：`run(dry=True, chi=0.2, tau_dry=3600)`。每步对每个簇求当前需求下的极限高度 h_lim（need = P_c 二分，
  上界取箱高，不再只在"已失败"时求）；z ≥ h_lim 的湿体素 → SALT_DRY（底层保持湿）；干体素只在 z < (1−χ) h_lim 且已干 ≥ τ_dry 时回湿。
  首版没有 τ_dry 时出现逐步的湿/干抖动（30 h 内 830 次回湿）：干掉顶层后簇的湿高度降到 h_lim 以下、判据恢复、全部回湿、再干……
  τ_dry = 1 h 是数值正则化（A），物理对应液体退出/回填的有限时间，未标定。
- 干体素系数 `dry_factor(z, d_sub)` = ε_s^1.5 / (1 + D_v/D_K(a(z)))，a(z) 按分层规则，用全场平均 d_sub（cv > 0 时的简化）。
- 内部前沿的蒸发计入簇抽液需求；前沿析出盐记入 m_front。
- 快速算例（λ = 4，c_k = 1e−6，δ_eff 5 mm）：3.9 h 冻结、顶层干化、之后稳定无抖动。
- 正式算例 `SCAN_DRY`（2014 条件）：λ = 32、16、8 与 λ = 32 + cv 0.2，frodo 上运行，结果见 README §7.4。

## 8. 原型结果（2026-09-03，README §7.4）

λ = 32/16/8 均在冻结后只干 1–3 层体素，E 不变（1.06/1.13/1.52）。机制上的原因：顶部干化去掉了填孔需求项，极限高度上移，湿前沿停在干皮下。
λ = 32 出现 104 次回湿并使结构缓慢抬升（松弛振荡的雏形）。要复现实验 0.1–0.3 的 E 需要 (i) 细端算例（d_sub ≤ 10 µm，顶层孔 ≤ 10 nm）、
(ii) ~1 mm 厚的干盖，即前沿退缩或致密化反馈（§2.3）。χ、τ_dry 应做敏感性；τ_dry 是数值正则化，不能进入结论。
