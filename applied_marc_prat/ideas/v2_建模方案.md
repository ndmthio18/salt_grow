# salt_grow_v2 建模方案（2026-09-02）

本文把 `ideas/`、`knowledge/` 与此前讨论收敛成一份可执行的方案：目标是什么、做成什么样、分几步、每步怎么验收。
方程见 `v2_model_formulation.md`（下称 **F§n**），盐域参数的体素实现见 `v2_盐域参数在体素模型中的实现.md`（下称 **I§n**），
参数出处见 `../knowledge/porous_salt_parameters.md`（下称 **K§n**）。本文不重复方程，只引用。

## 0. 项目目标

### 0.1 一句话

建立一个 **蒸发 → 毛细供液 → 离子输运 → 结晶 → 结构变化 → 蒸发** 闭环的外部盐生长模型：
输入基底孔径 d_sub、蒸发条件（RH、扩散长度 δ）和盐微结构类型，输出盐结构的形貌（patchy / crust）、
高度与覆盖率的演化，以及总蒸发率 E(t) 的反馈；并把基底面 z=0 做成可与孔隙网络模型（PNM）交换的接口。

### 0.2 要回答的科学问题

1. **基底孔径如何通过盐的多孔介质参数选择形貌**：d_sub 经 (k_s, P_cth) 走 2014 通道（供液门控，选方向与上限），
   经 d_c → a_v → Da* 走 2026 通道（定局部速率）。两条通道合起来能否给出"粗基底 patchy、细基底 crust"？
2. **形貌如何反过来改变蒸发**：patchy 期望 E ≈ 1 到 >1（外表面扩大），crust 期望 E ≪ 1（干盐层阻力 + Kelvin）。
   14× 降幅能否由"干盐低扩散率区 + 表面开孔分数"再现？
3. **供液上限是否限高**：在 k_s、P_cth 解耦的分级结构里 Π ≫ 1（不限高），在单尺度纳米孔结壳里 Π ~ 1（壳厚 ≈ H*）。
   门控分母含重力项 ρ_l g (L_s+h) 与黏性项 μUh/k_s（F§4、K§7）：patchy 由重力项控制（上限米量级，实验高度 ≤ 数 cm 远未触及，2014 估 1 mm 珠基底 Jurin 高度 4.5 cm），crust 由黏性项控制（毫米）。

| PNM 接口规范 | z=0 面上的输入输出数组与调用顺序，含一个 mock PNM 通过的测试 |

### 0.3b V1 预测什么、输入什么（2026-09-02 审查后的表述）

d_sub 经三条通道进模型：**微结构类型**（patchy / crust，定门控参数量级）与**成核密度**（定覆盖离散还是连片）在 V1 是输入，
按 d_sub 阈值与 structure_type 绑定默认值；**供液门控**（会不会干、干后 E 降多少）由模型计算。
V1 回答的是"给定微结构与成核密度后的形貌、动力学与蒸发反馈"；V2 由 PNM 表面浓度让成核密度涌现；微结构切换规则留 V3。
文献中没有 d_sub → 微结构的机理模型，把它做成显式输入而不是藏在参数里。

### 0.4 V1 明确不做（已决定）

wicking 之外的 drying；成核位置预测（V1 给定种子）；盐–基底脱离/缝隙状态；`SALT_PARTIAL` 的非饱和流；
patchy/crust 切换规则的预测（作为输入）；三维；干格回湿。理由见 I§9 与 F§5、§7。

## 1. 物理模型（引用，不重述）

六步闭环，每个事件步执行一次：

| 步 | 内容 | 方程 | 来源 | 相对 `../salt_grow` 的新旧 |
|---|---|---|---|---|
| 1 | 气相蒸汽 Laplace，湿盐面/湿基底 Dirichlet，干盐为低扩散率区，湿前沿 Kelvin | F§2 | 2014 + [A] | 干盐参与扩散是**新** |
| 2 | 湿界面局部生长律 V_n = G F(Da*) j | F§3 | 2026 | 旧（已验证） |
| 3 | 盐内 Darcy，界面需求 U_dem（含填孔项） | F§4 | 2014 + 2026 式 33 | 二维连续压力场是**新** |
| 4 | 门控 Π = P_cth/(p_atm − p_l)，Π<1 转干，迭代标记 | F§5 | 2014 式 6.8 | 旧规则、新的属性来源（界面体素 P_cth） |
| 5 | 界面推进：确定性填充、事件步 | F§8 | salt_deterministic [V] | 旧 |
| 6 | 新盐体素赋 birth properties，按 structure_type | I§3 | W25 + Licsandru + Piotrowski | **新** |

基底 z=0 在 V1 中只是边界（F§6），这正是 PNM 接口。

闭环里的"离子输运"在 V1 只有盐结构内部的反应边界层（Prat 2026 的 Da*，进 F）与内部湿前沿的析盐比例 F；基底内的离子输运与成核由 PNM 提供（V2）。
第 5 步加上内部湿前沿的供液与沉积密化（F§5.1，2026-09-02）。

## 2. 数值设计（2026-09-02 同步子计划后）

### 2.0 Regime 的操作定义（所有算例）

V1 = evaporation-wicking：基底始终饱和，只作 z = 0 边界；p_l,0 恒定（储液池深 L_s）；C_0 = C_eq；盐量无限。
生长停止只能由门控引起。drying 数据（Ben Amara、Eloukabi、Piotrowski、Wijnhorst 砂岩）只比"基底仍饱和、盐量未成限制"的早期段，判定规则见 `plan/09` §3。

### 2.1 网格、体素尺寸与计算域高度

- 维数无关实现（ndim 2 或 3），默认 2D 竖直截面，周期侧边，底部 z = 0 为基底面。
- **顶边**：实验样品管顶部开口于封闭箱，δ 是珠面到管口的凹陷深度（2014：2.5/7.5/15 mm；Ben Amara：15 mm），**无盖板**。
  计算域高度 δ_eff = δ + 管口外等效扩散长度（S1 用 2014 Table 1 标定），顶边强加 X_v∞。
  结构到达 z = δ 时模型几何失效（盐可伸出管口，周期条带不再成立），h_max ≥ δ − 2a 停止并报"到达几何有效上限"。
- **patchy 分支**：a = d_c,0 = 0.14 d_sub（F§8 [A]）。500 µm 基底 → a = 70 µm；δ = 15 mm、L_x = 20 mm → 约 6e4 未知数（不含管口外等效段），稀疏直接解可行。
- **crust 分支**：a 是纯数值选择（外层纳米孔无晶粒尺度），取 50–100 µm 使壳厚 H_lim ≈ 1 mm 有 ≥10 格。
- 气相域远大于盐域时可对气相用 z 向拉伸网格（efflorescence3d 已有），V1 先均匀。

### 2.2 每体素数组（I§8）

```
state   int8   GAS / SALT_WET / SALT_DRY / SALT_PARTIAL
phi     f64    固相填充度 [0,1)，仅 SALT_PARTIAL 有意义（不是液相饱和度）
eps_s, d_c, k_s, P_cth, r_p    f64   birth properties；eps_s 仅在内部湿前沿体素随沉积密化减小（F§5.1）
t_birth f64    生成时间 [s]
gen     int16  分级层序 n
```

### 2.3 求解器

两个 Laplace 型方程共用一个维数无关的有限体积组装器（F§13）：面系数调和平均，Dirichlet 半格系数 2，`spsolve`（3D 大规模换 CG）。

- **气相**：未知 X_v 在 GAS、SALT_PARTIAL、SALT_DRY；SALT_WET 与湿基底为 Dirichlet X_ve。SALT_DRY 的 D_eff = D_v ε_s^1.5 φ_o。
  SALT_DRY 与 SALT_WET 相邻的面（内部湿前沿）Dirichlet 值乘 Kelvin 因子 a_w,K(r_p)。与顶边不连通的气袋组装前剔除。
- **液相**：未知吸力 s = p_atm − p_l 在 SALT_WET；底行盐格 Dirichlet s_0；湿界面 Neumann U_dem（式 33，含填孔项）；
  **内部湿前沿 Neumann U_front = (j_front/ρ_l)[1 + F C_eq/(1−C_eq)]**（F§5.1）；干盐外表面零通量。
  重力作源项进面通量。无量纲化：s/P_cth,ref，避免 crust 的 k_s = 1e−22 病态。
- **门控**：解 s → 界面格 Π = P_cth/s < 1 标干 → 重解，至无新增；上限 10 轮报错。与基底不连通的湿子域整块转干。
- **前沿沉积**：Ṡ = F j_front C_eq/[(1−C_eq)ρ_cr]，dε_s/dt = −Ṡ/a 作用于前沿湿体素；ε_s ≤ ε_s,min = 0.05 [A] 时转 SALT_DRY、前沿后退。

### 2.4 事件步

```
loop:
  solve_vapor()                                   -> X_v; j on wet faces; j_front on wet/dry faces
  V_n   = G(eps_s) * F(Da*) * j                   interface voxels, prat2026.core
  U_dem = j/rho_l + [eps_s + rho_cr/rho_l (1-eps_s)] V_n
  U_front = j_front/rho_l * [1 + F C_eq/(1-C_eq)]
  solve_darcy(); mark_dry(); repeat until no new dry voxel   (<=10 rounds)
  dt = min over interface voxels of (1-phi) V_max / Vdot     (capped so that front eps_s change <= 0.01 per step)
  advance phi; flip voxels with phi >= 1-tol -> SALT_WET (tol=0.05, overflow redistributed); assign birth properties
  eps_s[front] -= Sdot*dt/a; voxels with eps_s <= eps_s_min -> SALT_DRY
  ledger: salt (top + front), water, J_tot, E, h_bar, h_max, eta, f_dry
  stop: t >= t_end | no wet interface and no wet front | h_max >= delta - 2a (geometry limit)
```

### 2.5 守恒账本与形貌分类

每步记录：沉积盐 = ∫G F j dt + ∫Ṡ ρ_cr dt；抽液 = ∫U_dem dt + ∫U_front dt；J_tot、J_ref（同网格、同 δ_eff 的无盐平面）。
形貌分类的操作定义（S4）：patchy = f_dry ≡ 0、η∞ < 1、E ≳ 1；crusty = f_dry 上升、η → 1、t_dry < t_cover；blocked = f_dry = 1、η = 1。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 纯 Laplacian 生长无内禀尺度，形貌不随网格收敛 [V] | 形貌指标不可声称收敛 | a 钉在晶粒尺寸；只报告总量（E、h̄、η）为收敛量，形貌为晶粒尺度定性 |
| 2D 夸大屏蔽（E 2.04 对 3D 1.10）[V] | E 偏高 | 求解器维数无关；E 的定量报告用 3D 算一次；2D 只报趋势 |
| crust 分支系数病态（k_s=1e−22） | Darcy 解失真 | 无量纲化；记录条件数；用一维闭式做每步核对 |
| 两态湿/干闭合 [A] | 缺 k_r,s(S)、p_c,s(S) | 明说等价于阶跃保持曲线；不引入无数据的闭合 |
| 标干循环不收敛/振荡 | 事件步卡死 | 单调标记（干格不回湿）保证有限步终止；上限 10 轮报错而非静默继续 |
| crust 分支的 φ_o、k_s·P_cth 都是反标定 | E 与壳厚平台都不是独立验证 | 独立预测是动力学：到达平台时间、η(t)、E(t) 形状、平台后缓慢增厚（前沿密化）；争取 Nachshon 2018 / Piotrowski 型气测数据 |
| Ben Amara 是 drying | 后期不可比 | 只比早期饱和阶段，按 plan/09 §3 判定并在图上标出；regime 匹配组（2014、Norouzi Rad）作定量判据 |
| 顶边 Dirichlet 是近似（管口开口，无盖板） | J_ref 与 E 依赖 δ_eff | S1 用 2014 Table 1 标定 δ_eff；结构到管口即停，报"几何有效上限" |
| d_sub → 微结构类型与成核密度都是输入 | 模型不预测 patchy/crust 切换本身 | 论文表述为"给定二者后的后果"；V2 让成核密度从 PNM 浓度涌现；切换规则留 V3 |
| 内部前沿密化只改 ε_s，不改 k_s、r_p [A] | 密化后 Kelvin 与渗透率偏乐观 | 报 ε_s,min 敏感性；V2 让 r_p、k_s 随 ε_s 缩放 |
| 分级规则 h_1、α、减半下限均为 [A] | patchy 的 P_cth 序列不确定 | I§7 预期 patchy 对其不敏感；用 M6 的敏感性矩阵证实，若敏感则升级为标定量 |

## 7. 已定决策（不再讨论）

1. 先 wicking，后 drying（F§10）。
2. 外部盐是多孔域，永远不是不透水固体层。
3. k_s 与 P_cth 是两个独立输入，禁止用同一孔径经 Carman–Kozeny 同时推出（K§3 [V]）。
4. 微结构类型 structure_type 与成核密度都是输入（d_sub 的两条经验通道），切换规则不预测；门控由模型计算。
5. 体素尺寸 a = 0.14 d_sub（patchy）；crust 分支 a 为数值选择。
5b. δ 是管口凹陷深度（无盖板），计算域高 δ_eff = δ + 管口外等效长度；结构到管口即停（几何上限，非物理停止）。
6. 确定性填充，不用随机容量（等价于非均质 ε_s，V1 不要）；事件步允许填充度 ≥ 1−tol 的格同时翻转（数值参数）。
6b. 求解器维数无关，默认 2D，E 的定量报告用 3D 算一次。
6c. 内部湿前沿有供液与沉积密化（formulation §5.1），不用零通量。
7. 干格不回湿。
8. 盐–基底脱离/缝隙不考虑。
9. 干盐作为低扩散率区参与气相解，不引入独立的壳阻力参数；壳侧唯一标定量是 φ_o。
10. 只在物理量空间比较（F、dh/dt、E、h），不做 Da* 反演。
