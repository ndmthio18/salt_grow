# 盐域多孔介质参数在二维体素模型中的实现

配套 `v2_model_formulation.md`（方程）与 `结晶盐作为新生多孔介质_物性与建模启示.md`（物性证据）。
本文回答一个问题：**盐结构的 ε_s、孔径、k_s、P_cth、D_v,eff、Kelvin 半径、接触状态，在体素模型里放在哪、怎么赋值、谁标定、对结果影响多大。**

---

## 1. 总原则：孔隙是亚格子属性，界面才是几何

体素尺寸 a = d_c,0 = 0.14 d_sub（500 µm 基底给 70 µm）。盐结构内部的孔（微米到纳米）永远小于体素，
所以**体素模型不分辨盐的孔隙，只分辨"多孔盐聚集体 / 空气"界面**。多孔介质参数全部作为**每个体素的属性场**进入方程，
不作为几何。这与 Prat 2026 的尺度分离一致：反应边界层 δ_C（微米级）≪ 体素 ≪ 结构（毫米级）。

结论性的一句话：**盐的多孔介质参数决定"长多快、能不能供液、干了之后透不透"，几何演化只负责"往哪长"。**

## 2. 参数进入哪条方程

| 参数 | 进入的方程（编号见 formulation） | 用哪个体素的值 |
|---|---|---|
| ε_s | 体素容量 (1−ε_s)a²（§8）；前因子 G（§3）；填孔需求项 ε_s V_n（§4）；干盐 D_v,eff（§2）；液相曲折度 | 当前体素 |
| d_c | 体素尺寸 a（全局，取 d_c,0）；a_v = 5(1−ε_s)/d_c → Da* → F（§3） | **界面体素**（沉淀发生在最外层） |
| k_s | 盐内 Darcy（§4），面通量用相邻体素的调和平均 | 沿流径的**所有湿体素**，串联 |
| P_cth | 干涸门控 Π（§5） | **界面体素**（弯月面在最外层） |
| r_p（Kelvin） | 干盐湿前沿的 a_w,K（§2） | 湿/干交界处的湿体素 |
| D_v,eff | 干盐体素的气相扩散率（§2） | 当前干体素 |

这张表本身已经给出了 **k_s 与 P_cth 解耦的实现方式**：Darcy 读的是结构内部所有体素（老的、粗的），
门控读的是界面体素（新的、细的）。只要每个体素的属性在**生成时**按分级规则赋值，Wijnhorst 2025 的"粗内孔给 k、细外孔给 P_c"
就自动成立，不需要任何额外的解耦参数。

## 3. 属性在体素生成时赋值（birth properties）

每个盐体素在翻转为 `SALT_WET` 时记录：`t_birth`、`generation n`、`eps_s`、`d_c`、`k_s`、`P_cth`、`r_p`。之后不变，**唯一例外**是内部湿前沿体素的 `eps_s` 随沉积密化减小（formulation §5.1，2026-09-02）。

生成规则由 `structure_type` 选择：

### 3.1 `PATCHY_POROUS_SALT`（粗基底，d_sub ≳ 200 µm）

```
d_c(n)   = d_c,0 · r^n,      r = 1（Prat 2026 自复制）或 0.5（Wijnhorst 逐层减半）
a_1(n)   = d_c(n)/4                                  内孔
eps_s    = 0.43（r=1）或 0.20（r=0.5）
k_s(n)   = c_k · 2^n · a_1(n)^3 / (12 d_c,0)   W25 原式（缝数每层加倍；2026-09-02 更正，此前漏 2^n）；c_k ≤ 1 为有效导通折减，与 A_r、c_h 合成标定组 β_1（plan/13）
P_cth(n) = 2 γ cosθ / a_1(n)
r_p(n)   = a_1(n)/2
```

层序数 n 由体素生成时的高度决定：h_1 = c_h d_sub（W25：0.1 mm ≈ 10 d_1，c_h ≈ 1），h_i = α h_{i−1}，α=2（Wijnhorst 算例），
即 n(z) = floor(log₂(1 + z(α−1)/h_1))。减半到 d_c < 某下限（取 1 µm，[A]）后停止减半。

标定锚点：k_s(0) 对 240 µm 砂应给 ~5e−12（Piotrowski 2020，实测/立方律 ≈ 3，可用一个 O(1) 前因子 c_k 吸收）。

### 3.2 `NANOPOROUS_CRUST`（细基底，d_sub ≲ 100 µm）

```
eps_s  = 0.25
k_s    = 2.5e−22 m²（扫 1e−22 ~ 1e−21）
P_cth  = 2 γ cosθ / r_p，r_p = 3.5 nm  → ≈ 4e7 Pa
r_p    = 3.5 nm（Kelvin 用同一值）
D_v,eff/D_v = eps_s^1.5 · φ_o，φ_o = 表面开孔分数，由 14× 标定（总开度 D_v,eff/D_v 预期 ~5e−3，即 φ_o ≈ 4e−2；见 plan/05）
```

不做分级（无证据）。k_s 与 P_cth 仍是两个独立输入，只是这一支两者都来自 Licsandru 的反演，
**乘积 k_s·P_cth 才是被约束的量**（壳厚 = H*），单独的 k_s 或 P_cth 各自可以差一个量级而不改结果。

### 3.3 `SUBFLORESCENCE_CLOGGED_PM`

V1 不实现：基底未离散。进入 PNM 阶段后按 Dong 2021 的方向修改**基底**孔喉属性，不属于 Ω_salt。

### 3.4 分支如何选

V1：按 d_sub 阈值（100–200 µm）由输入指定。这是显式承认"切换规则未知"，把它做成输入而不是藏在参数里。
知识库 §8 已证明：从 patchy 参数按 d_sub 缩放永远得不到 crust（含重力与黏性的 H_lim 在 25 µm 仍约 8 m，实验高度 ≤ 数 cm），所以不存在"一套参数走到底"的选项。

## 4. 湿、干、部分饱和三种状态的闭合

| 状态 | 液相 | 气相 | 需要的闭合 | V1 |
|---|---|---|---|---|
| `SALT_WET` | Darcy，k_s | Dirichlet X_ve（界面） | k_s | 有 |
| `SALT_DRY` | 无 | 扩散，D_v,eff；湿前沿 Kelvin | D_v,eff、r_p | 有 |
| 内部湿前沿（`SALT_WET` 紧邻 `SALT_DRY`） | Neumann U_front，沉积使 eps_s 下降 | 前沿面 Kelvin 蒸发 | F(Da*)、eps_s,min | 有（2026-09-02 加入） |
| `SALT_PARTIAL`（0<S<1） | k_r,s(S)·k_s | D_v,eff(S) | k_r,s(S)、p_c,s(S)、D_v,eff(S) | **无，显式标为缺失** |

V1 用两态（湿/干），理由与证据边界：

- Piotrowski 2020：NaCl 壳湿态与干态气体渗透率相近（烘干失重 20 % 却不改 k），说明 NaCl 里残留水在不导气的孔中，
  两态近似对 NaCl 的气相侧是可接受的；对 MgSO₄（差两个量级）则不行。
- 液相侧的 k_r,s(S) 无任何数据。两态模型的含义是 S 从 1 直接跳到"残余"，等价于 p_c,s(S) 是阶跃函数、阈值 P_cth。
  这是 [A]，在结果里要写明。

回湿：V1 不允许（干格永久干）。V2 若加回湿，需要 p_c,s(S) 的吸液支，仍无数据。

## 5. 盐–基底接触状态（**暂不考虑**，2026-09-02 决定）

> 用户决定：V1 不引入接触/脱离状态，f_contact、h_gap、人为脱离敏感性一律不做。以下保留为设计备忘，供 drying 扩展时启用。

新增底层体素的接触标记 `CONTACT / GAP`，以及两个诊断量：

    f_contact = 与基底湿接触且液压连通的底层盐体素数 / 被盐覆盖的基底长度
    h_gap     = 基底与盐底面之间 GAS 体素的平均高度

实现上不需要新方程：`GAP` 只是把该底层体素下方的一格改成 `GAS`，于是

- 该盐柱失去 p_l 边界 → Darcy 无 Dirichlet → 判定为无供液 → 整柱按 §5 门控转干；
- 蒸发路径自动变为 基底湿面 → 缝隙气相 → 干盐扩散 → 空气，正是 Nachshon 2018 的架空图景；
- E 与覆盖率的响应由现有方程给出。

**缺失的是缝隙形成的机制**。Licsandru 2022 的图景（底部溶解、顶部再沉淀、盐壳上移）需要基底浓度低于 C_eq，
在 C_0 ≈ C_sat 的 wicking 里不会发生；Nachshon、Licsandru 都是 drying 观测。所以 V1 只做两件事：
(a) 把 f_contact 作为输出诊断（它会因门控干涸而自然下降）；(b) 允许**人为规定**脱离（时间、比例）做敏感性，
回答"架空后 E 降多少、形貌怎么变"。机制留到 drying 扩展，届时基底浓度场可用。

## 6. 参数既是输入也是输出

用户笔记的核心判断是 𝒫_salt = f(d_sub, j, RH, C_0, 历史, 形貌)。体素模型里这句话的落地方式：

- **输入**：分支规则与生成规则（§3），由 d_sub、RH（经 X_v∞ 进 j）、C_0（经 a_w）决定。
- **历史**：`t_birth`、`generation` 使每个体素带着它生成时的条件；分级规则让老体素粗、新体素细。
  内部湿前沿的密化已让 ε_s 随历史变化（formulation §5.1）。V3 可让 ε_s 或 d_c 依赖生成时的局部 j 或 F（Prat 2026 的 C_top − C_eq 与 j 成正比，是天然的"生长速率→微结构"钩子），
  目前无数据，不做。
- **输出**（每步可算的结构级有效量，用于与实验和 PNM 对接）：
  - 有效渗透率 k_eff：对整个 `SALT_WET` 域施加单位压差解一次 Darcy；
  - 有效毛细阈值：界面体素 P_cth 的最小值（最先干的地方）；
  - 有效蒸汽阻力：无盐时 J_ref 与当前 J_tot 之比 E；
  - h̄、h_max、覆盖率 η、箱计数维数。
  PNM 需要的正是这些结构级量，而不是体素属性。

## 7. 哪些参数真正影响结果（预期，待数值证实）

| 分支 | 强影响 | 弱影响 | 依据 |
|---|---|---|---|
| patchy | ε_s（容量与 G，线性进时钟）、Da*（F，0.5–0.93）、δ 与 RH（j） | **k_s、P_cth**：只要 Π ≫ 1，形貌与速率对二者不敏感；2014 把 k_s 降 1e−6 形貌不变 | 知识库 §8 的 H_lim 估计（含重力，米量级；patchy 里黏性项比重力项小 1–2 个量级，故 k_s 几乎不进判据） |
| crust | 乘积 k_s·P_cth（H*，定壳厚与横向铺展）、φ_o（定 E）、ε_s（容量） | k_s 与 P_cth 各自的拆分；r_p 在 Kelvin 里只在 <10 nm 才起作用 | 2014 Fig 26、§8 结论 2 |

这直接告诉实验和标定往哪使劲：**patchy 要测 ε_s（micro-CT 足够），crust 要测 k·P 乘积与表面开孔分数（壳厚平台 + 蒸发降幅）。**
Piotrowski 型的气体渗透率对 patchy 分支是"锦上添花"，对 crust 分支才是关键，而他们恰恰没测细质地样品。

## 8. 数据结构与检验

每体素数组：`state, phi, eps_s, d_c, k_s, P_cth, r_p, t_birth, gen`；
每分支一个 `SaltConstitutive`：`eps_s(n), d_c(n), k_s(n), P_cth(n), r_p(n), Dv_eff(eps_s), phi_o`。

必做的检验（加进 formulation §12）：

1. 单位：k_s [m²]、P_cth [Pa]、U_dem [m/s]、D_v,eff [m²/s]；Π 无量纲。
2. 一维分级柱：n 层串联的压降与 Wijnhorst 式(3) 一致（解析可算）。
3. 均匀 k_s 下把 k_s 扫 6 个数量级，patchy 形貌应逐格不变直到 H* 接近结构高度（复现 2014 的不敏感性）。
4. crust 分支：壳厚平台 ≈ H*（用降幅后的 j），E 由 φ_o 单调控制。

## 9. 明确不做与原因

- 不解 `SALT_PARTIAL` 的非饱和流：无 k_r,s(S)、p_c,s(S) 数据，用干态 k_s 代替会错（Piotrowski 的 MgSO₄ 差两个量级）。
- 不预测 patchy/crust 切换：用输入分支。
- 不考虑盐–基底脱离与缝隙（用户决定，见 §5）。
- 不用 Nachshon 2011 的"D_v,eff 低两个量级"：原文只支持蒸发率降近一个量级（用户笔记已纠正）。
- 不用 Dong 2026 Geoderma 的百分比：无原文。
