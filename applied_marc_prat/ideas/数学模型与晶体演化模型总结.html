1. 模型定位

核心目标：不预先指定 patchy 或 crusty，而是让基底输运、成核分布、气相屏蔽、盐簇供液能力和簇间合并共同决定最终形貌。

基底孔结构孔径、喉道、压力、盐浓度与非均匀输运
成核与盐簇过饱和触发种子，产生外部多孔盐结构
蒸汽扩散几何改变局部蒸发；尖端增强、邻区屏蔽
生长与供液Prat生长律和分级毛细供液共同推进界面
反馈闭环：新几何 → 新蒸发场 → 新生长速率与抽液需求 → 新压力/浓度场 → 新成核和新几何

当前适用工况

主模型

Evaporation–wicking：基底始终饱和，底部持续供液，盐库不耗尽。

气相

准稳态纯扩散；外部对流用等效扩散距离 δeff 吸收。

尚不包含

完整非饱和 drying、Richards 方程、力学开裂与结晶压力。

2. 区域、状态与主要未知量

最小模型由基底域 Ωp、随时间演化的盐域 Ωs(t) 和外部气相 Ωg 组成。当前代码中基底仍是表面孔层加储液池喉道的原型，盐和气相使用三维体素。

3. 气相蒸汽输运与蒸发通量

气相时间尺度远短于晶体生长，采用准稳态扩散：

∇·(ρgDeff∇Xv) = 0

边界条件：

远场：Xv = X∞　｜　湿盐：Xv = aw(Ceq)Xsat　｜　裸孔：Xv = aw(Ci)Xsat

侧边周期；非孔口底面无通量。有限计算箱上方增加长度 Lext 的一维串联扩散段，使 δeff = zbox + Lext。

j = −ρgDeff∇Xv·n

突出尖端聚集扩散通量，邻近裸露表面则受到屏蔽。因此气相方程既决定生长速度，也产生盐核之间的竞争和潜在排斥区。

4. 基底孔网中的压力与盐输运

4.1 液体压力

圆柱喉道采用 Hagen–Poiseuille 导度：

gij = πrij4 /(8μLij)

孔节点满足 Kirchhoff 守恒：

Σjgij(pj−pi) + giR(pR−pi) = qi

qi来自裸孔蒸发或其上盐簇的抽液需求。储液池压力与浓度采用 Dirichlet 条件。

4.2 溶解盐输运

孔中盐质量为 mi = ρℓViCi。喉道盐通量由上风对流和扩散组成：

Fs,ij = ρℓ[QijCup + dij(Ci−Cj)]，　dij = DsAij/Lij

时间上采用 backward Euler。蒸发只移走水，盐不挥发；补液流动和扩散共同控制表面富集。

◆ 这一节描述的是哪个驱动。§4 的孔层液压与盐输运只存在于三维预实验驱动（runs/E1_pre/pre_experiment.py、pre_experiment_vapor.py）。当前用于全部粒径验证的二维闭环驱动（runs/E2_feedback/feedback2d.py）没有浓度场、没有储液池喉道、没有成核：种子在 t = 0 预设在每个孔口上（宽 0.77 孔距，θ0 = 0.83），种子的盐在台账里记作 salt_nucleated。它的供液只用 first_failure_height 的分级阻力算高度上限。
三维预实验的简化：只离散了单层表面孔和一根 0.7 mm（或 22 mm）的储液池喉道，尚未离散完整基底柱。富集体积是一个孔（Vpore/Epore ≈ 0.3 h），而真实基底的富集区是整根液柱（ℓC = D/U ≈ 数 cm > Ls），时间尺度是小时到天。因此成核偏早、且各孔几乎同时。

5. 过饱和成核模型

定义饱和度：

Si = Ci/Csat

裸露孔满足以下条件时成核：

Si ≥ Snuc，　当前 Snuc = 1.20

成核后，在对应孔口足迹上放置一层湿盐体素，并将该孔浓度恢复到饱和值。最终版本可进一步采用过饱和度相关的概率成核率：

Pnuc = 1 − exp[−J(S)ΔAΔt]

模型不预设固定排斥半径。已有盐簇通过蒸汽屏蔽和抽液改道降低邻区富集，排斥长度 Lex应作为计算输出。

◆ 孔径分布给不给出不同的成核时刻——实际算出来的

直觉上：初始浓度与实验相同（C0 = 0.25），孔有孔径分布，各孔富集到 Snuc 的时间应该不同，于是成核有先后、有选择。三维预实验（runs/E1_pre/README.md §3、§6、§7）检验了这一点，结论分两种情形：

情形成核说明
λ = 1，C0 = 0.25，储液喉道 0.7 mm（Pe ≈ 0.3）6/25；最大的一对孔（283 µm）1.26 h 先成核，其四个邻孔 3.03 h 成核，其余 19 孔停在 C/Csat = 1.13–1.14 永不成核有选择性——但只因为稳态富集上限（≈1.3）刚好压着阈值 1.2，大孔的孔口面积/体积比先越线；C0 = 0.24 则一个都不成核
λ = 1，C0 = 0.22，储液喉道 22 mm（2014 的 Ls，Pe ≈ 3）25/25 于 0.45 h 同时无选择性。富集快而均匀，先越线的和后越线的差不到一个时间步
λ 扫描（1/4/8/16/32，C0 = 0.22，22 mm，蒸气场）25/25 于 1.0 / 0.19 / 0.09 / 0.05 / 0.02 h越细越早、越同步；屏蔽来不及影响成核

所以：是，模型按浓度算成核，孔径分布确实给出不同时刻；但在实验的几何（深储液池、Pe ≈ 3）下这个差别小到可以忽略，所有孔一起成核。原因是"孔 + 喉道"把富集体积缩到一个孔，真实的富集是整根 22 mm 液柱上的浓度峰（2014 §4 的对流–扩散场），加上界面喉道通量的孔尺度涨落（2014 图 9d–i 的 PNM）——两者都还没有。2014 表 2 的实测首次析出时刻：δ = 15 mm、Ls = 22 mm 下 1 mm 珠 10 800 s，100–125 µm 5 400 s，50–62 与 5–50 µm 各 4 800 s（1.3–3 h）；同一珠子把 δ 从 15 mm 压到 2.5 mm，析出时刻从 30 600 s 缩到 300 s——通量只变 1.34 倍，时刻变 102 倍。这条曲线目前模型不具备复现能力。

6. Prat局部生长律

初生盐晶尺度继承基底尺度：

dc,1 ≈ 0.14dsub，　av = 36(1−εs)/dsub，　Ds,eff = √εsDs

高度无关的 Damköhler 数：

Da* = β2(1−εs)2(1−Ceq)kr /(εsDs,effav)

局部结晶效率：

F(Da*) = √Da*/(1+√Da*)

湿盐—气体界面的法向速度：

Vn = [Ceq /(ρcr(1−εs)(1−Ceq))] F(Da*)j

这说明局部生长速度与局部蒸发通量线性相关。Da*主要修正生长效率；若空间上均匀，它主要改变时钟而非形貌。

生长造成的液体需求

Udem = j/ρℓ + [εs + (ρcr/ρℓ)(1−εs)]Vn

第一项补偿蒸发；第二项负责填充新生盐体孔隙并输送即将析出的盐。簇总需求为 Qc = Σf∈cUdem,fAf。

正则化长度 ℓ ▲

Laplacian 生长没有内禀长度：任何尺度的凸起都被放大，最细的针只受体素限制，形貌随 dt 与网格变（旧代码柱宽 48 → 34 → 24 格，冻结高度不收敛）。因此把沉积速率沿生长前沿在 ℓ 上做守恒的高斯平滑后再推进占有率：

V̇i → ΣjKℓ(i−j)V̇j，　K̂ℓ(k) = exp(−k2ℓ2/2)

波长短于 ℓ 的失稳被压掉，结构横向尺寸约 4–9 ℓ。约束：3a ≤ ℓ < 孔距/2（ℓ ≥ 孔距时相邻孔的结构被抹成横贯周期箱的平板，收敛平凡），箱宽 ≥ 10 ℓ。当前取 ℓ = 0.25 dsub（A）。

ℓ 的代价：ℓ 决定针的粗细，粗细决定尖端通量，结构长高速度大致 ∝ 1/ℓ（三维 λ = 16：ℓ/d 0.15 比 0.25 快 2.4 倍，0.35 慢到 0.75 倍），覆盖率也随 ℓ 变（0.15 留裸面，≥ 0.25 整面覆盖）。ℓ 不得用 2014 蒸发曲线调；应由结构横向尺寸约束：Wijnhorst 2025 SEM（0.95 µm/px）纹理自相关给微晶 7–17 µm、次级团 48–88 µm、花菜团 0.3–0.5 mm，按次级团反推 ℓ/dsub ≈ 0.06–0.15。

7. 分级晶体演化模型

“分级”不是把盐预先切成真实水平薄层，而是用高度区间近似不同生长代际：越往外，晶体和孔道越细，所占结构尺度越大。

多孔基底：dsub
第1代dc,1，a1，h1
第2代d/2，a/2，2h1
第3代d/4，a/4，4h1
第4代更细外层
dc,n = dc,12−(n−1)，　an = a12−(n−1)
hn = h12n−1，　h1 = chdsub，当前 ch=1
Hn = Σhm = h1(2n−1)
n(z) = 1 + floor{log2[1+z/h1]}

因此第一代位于 0 ≤ z < h1；第二代位于 h1 ≤ z < 3h1；第三代位于 3h1 ≤ z < 7h1。当前代码按体素中心高度判代，而非追踪真实晶体亲子关系。

关键竞争：孔径减半使毛细压力提高约2倍，但层厚加倍、渗透率降为约1/4，使该层黏性压降提高约8倍。因此“黏性损失/毛细能力”每代约放大4倍，最终发生水力失连。
参数解耦原则：真实盐结构的渗透率可能由少数粗而贯通的内部通道控制，毛细阈值可能由最细外层孔喉控制，蒸汽扩散又受开放孔比例控制。不能把 ks、Pcth 和 Ddry 当作同一个孔径唯一决定的材料常数。

9. 供液极限与 patchy–crusty 转变

对盐簇高度 h，定义底部吸力 sfoot 和按簇足迹面积折算的需求速度 U = Qc/Afoot。维持顶部湿润所需压力为：

Pneed(h) = sfoot + ρℓgh + μUΣnℓn(h)/kn

与当前外层的毛细阈值比较：

Π = Pneed/Pcth,n(h)

Π ≤ 1：供液充分

突出尖端蒸发最强，顶部持续向上生长。盐簇保持高而分离，倾向 patchy。

Π > 1：顶部失连

顶部停止或干化，低处侧面仍可供液并横向生长；相邻簇合并，倾向 canopy/crust。

由于 h1 ∝ dsub，若临界代数 n*大致不变，则：

h* = h1(2n*−1) ∝ dsub

细基底对应更低的物理失连高度，粗基底则可能在到达实验管口前始终不失连。

冻结的自洽求法与自封闭 ▲

需求 U 取决于哪些面在生长，而生长面集合又由 hlim 决定，故每簇求不动点 h* = hlim(U(h*))：U(h) 只对 h 以下的面计填孔项，蒸发项对所有湿面无条件计入；Φ(h) = hlim(U(h)) − h 单调，二分求根；外层对孔网压力 q → p → sfoot 欠松弛迭代（ω = 0.5）至活跃面集合不变。不收敛即抛错，不静默继续。

hlim 以上的面速度置零但仍蒸发，其盐无处可去，按 F j Ceq/(1−Ceq) 填入背后体素的孔隙（从供液孔同步扣除），εs ≤ εmin 时变 SALT_SEALED；封闭时间 τseal = (εs,0−εmin) a ρcr(1−Ceq)/(F j Ceq) 由质量平衡给出，不是新参数。全封闭后 E = Eresolved + φvent fblocked，阻断列 = 该列的蒸发面没有通向远场的气体路径（顶盖上方的空气虽连通但不算）；φvent ≈ 0.07 由 2014 的 14 倍降幅标定，是标定量不是预测。

三维小箱（2×2 孔、λ 32）实测：簇长到 hlim = 91 µm 停止，12 h 封顶，Eresolved → 0，fblocked = 1。

未来软门控

正式模型计划使用连续水力可达性：

Ah(Π) = 1/{1+exp[α(Π−1)]}，　Vn = AhGFj

硬冻结是 α → ∞ 的极限。软门控可以直接分析垂向和横向生长速度之比。

10. 干盐、内部湿前沿与致密化

10.1 干盐中的蒸汽扩散

干盐不是不可穿透固体，而是低扩散率多孔介质：

Ddry,n = εs3/2[1/Dv + 1/DK,n]−1
DK,n = (an/3)√(8RT/πMw)

10.2 Kelvin修正

湿盐—干盐内部前沿的平衡活度应降低：

aw,K = exp[−2γcosθMv/(ρℓRTrp)]

10.3 前沿供液和析盐

Ufront = (jfront/ρℓ)[1 + FCeq/(1−Ceq)]
dεs/dt = −FjfrontCeq/[a(1−Ceq)ρcr]

前沿持续析盐会降低孔隙率，并应反馈降低 ks 和 Ddry、改变 rp 与 Pcth，从而形成“干化—致密化—阻力增加”的正反馈。

当前证据边界 ▲：逐体素 εs、rp、ks、Pcth、Deff 已随出生高度赋值并随前沿析盐致密化（saltv2/crust.py），水/盐台账残差 1e−13/1e−15；状态机首版不可逆，回湿（χ、τdry）只保留作旧结果复现。局部液体饱和度方程、逐面 Kelvin 条件、ks(εs) 反馈仍未做（plan/17 V4）。

11. 数值推进与耦合顺序

  1. 根据当前 GAS/SALT_WET/SALT_DRY 几何构造气相计算域。
  2. 求解准稳态蒸汽扩散，得到裸孔和所有湿盐界面的逐面通量 j。
  3. 识别周期边界下的盐簇、簇足迹和创始孔。
  4. 由 Prat 生长律计算逐面 Vn 与 Udem，汇总每个盐簇的抽液量。
  5. 在基底孔网中求解压力和喉道流量，再用隐式格式更新各孔盐浓度。
  6. ▲ 供液不动点：逐层扫描 Pneed−Pcth 求 hlim，与孔网压力外层迭代至活跃面集合不变。
  7. ▲ 冻结湿面与内部湿干前沿的析盐率映射到具体体素；生长带走的盐从供液孔扣除。
  8. 检查 C/Csat ≥ Snuc，在新孔口成核。
  9. ▲ 沉积速率在 ℓ 上平滑后更新体素占据率：dfi/dt = ΣVn,fAf/Vcell。
  10. ▲ f ≥ 1 的体素翻转为湿盐，溢出只分给该体素自己的气相邻格（旧版全域汇总分配是簇间的非局部耦合，也是唯一随 dt 变的横向平滑）；新体素由翻转掩膜初始化出生属性。
  11. ▲ 执行 WET → DRY_OPEN → SEALED，重解用于记录的气相场，写入具名输出与质量台账。

▲ 时间步 Δt = min(r Δtgrow, r Δtnet, Δtseal, r Δtsalt, r Δtcap, Δtend)：Δtgrow 按候选体素的总占有率增量（fmax = 0.5）而非单面速度；r 是收敛测试的缩放因子，只乘精度型限制器，事件型（封闭、终止）不乘，否则以 (1−r) 的几何级数逼近事件而到不了。基准算例里 dt 由 Δtnet 决定。气相只在几何或状态改变时重解（禁止"每 N 步"），上一时刻场热启动；只解到最高盐体素上方一个横向周期，其余高度并入顶部一维外段（与全箱解 E 差 1e−5，早期快 10 倍）；CG 相对容差 1e−8（E 对容差敏感：1e−7 误差 1e−3，1e−5 改形貌）。

13.4 三维预实验的形貌结果（E1_pre §7.1，ck = 3×10−3，δeff 5 mm，旧闭合）

同一孔距（0.7 mm/λ）、同一种子（25 孔同时成核）、同一 ck：λ = 1、4（1080、270 µm）24 个簇竖长到箱顶，不合并、不贯通，顶盖覆盖 0.47–0.51，θ 0.39——patchy；λ = 8、16、32（135、68、34 µm）在 2.26 / 1.60 / 0.87 mm 冻结，以下横向铺开，顶盖覆盖 1.00，其下 55–61 % 裸孔——"顶盖式壳"。转变在 135–270 µm。这是用旧闭合、旧 ck 得到的，绝对数不引用，但形貌分支本身在三维里出现了。

13.5 ◆ 为什么二维模型形成不了 patchy

实验里 patchy 靠三件事维持：稀疏成核（2014 图 20：δ = 15 mm 时 1 mm 珠约 40 个结构/1134 mm²，间距 5.3 mm，个数由通量决定）；屏蔽 + 汇让裸基底不再成核、小斑块溶解；顶端生长使结构高而孤立。按对当前代码和 E1_pre 记录的核对，原因分层如下（顺序即权重）：

  1. 维度（首要）。二维 x–z 加周期侧边，一排柱顶连成一线 = 完整的屋顶，气相被封死；三维里同样的东西是一排篱笆。13.4 表明三维在同样的孔距种子下粗基底保持 patchy——所以把 patchy 的缺失主要归于间距（09-09 的判断）是错的，主要是二维。
  2. 种子间距绑在孔距上。模型 0.70 mm（1 mm 珠）到 0.022 mm（34 µm），实测 2.7–5.3 mm 且随通量而非孔距变。这是一个真实的定量错误——影响斑块密度、E 的升高幅度、可能也影响转变位置——但从 13.4 看它不是三维里 patchy 的障碍。
  3. 没有成核选择。二维驱动无成核；三维驱动有阈值成核但在 2014 几何下同时成核（§5）。稀疏、由通量决定的斑块密度需要基底柱输运 + 成核（模块 1、2），未做；溶解（"死亡"）也未做。
  4. 冻结面规则与 2014 §6.2 不同（待验证）。本模型冻结面继续蒸发并把盐沉进反应带、原地致密封闭（plan/16 M2）；2014 格子模型里毛细失败的格子变成干的零蒸发屏障，通量赶到下方湿面横向长。前者让顶端自己封死，后者让底部摊开。这条只核对了代码与论文，没有做分离实验。

不是原因的：生长律（Vn ∝ j 本身给出顶端快、侧面慢的花椰菜形，2014 §6.2 同样的规则长出了 patchy）；供液闭合（它让细基底低处冻结、横向铺开，这部分在二维和三维都工作；模型错的是粗端，而粗端在三维里是对的）。

◆ 由此改变的下一步：不做二维种子间距扫描（二维里再稀也会在一排上合拢）；优先把导汽壳、基底盐、前沿追踪移植回三维驱动，在三维里重跑 2014 四档。之后才轮到 ck 扫描、εmin/m 的依据、基底柱输运与成核。
现阶段不能声称 ◆：转变粒径的绝对位置（斜率差 1.4 倍，且二维无 patchy）；封闭后 E 平台的数值（εmin、m 为假设）；膝宽（不收敛）；成核时刻与密度（输入）；50–62 µm 的阶段 3 回升；patchy 档 E > 1 的升高；一切 drying 后期。
