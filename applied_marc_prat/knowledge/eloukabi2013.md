# Eloukabi, Sghaier, Ben Nasrallah, Prat (2013) —— crusty–patchy 转变的实验与毛细柱模型

*Experimental study of the effect of sodium chloride on drying of porous media: The crusty–patchy efflorescence transition.*
Int. J. Heat Mass Transfer 56, 80–93. 文件：`literature/1-s2.0-S0017931012007478-main.pdf`

**regime：drying**（初始饱和、无补给）。

## 实验条件（§2）

| 项 | 值 |
|---|---|
| 基底 | 玻璃珠 6 档：#1 5–50、#2 50–62、#3 100–160、#4 200–250、#5 250–270、#6 300 µm |
| 容器 | Plexiglas 圆柱，直径 2 cm、深 1 cm；壁面接触角≈80°，抑制壁面爬盐 |
| 环境 | T≈30 °C，RH≈3±2 %（硅胶） |
| 初始浓度 C0 | 0、12.5、25 %（质量分数）；另在 50–62 µm 上做 7–25 % 系列 |
| C_sat | 26.6 %（30 °C） |
| 测量 | 质量每 2 min，俯视照片每 5 min |
| 代表性蒸发通量 | j ≈ 1e−4 kg/m²/s（§4 模型用） |

## 主要观测

- **形貌**（§3.5，Fig 3）：#1–#3 结壳（crusty），#4–#6 离散斑块（patchy）；形貌与 C0 无关（结论 7）。
- **水回收率 F**（§3.6，Fig 8）：C0=25 % 时，平均粒径 <200 µm 回收率随粒径升；≥200 µm 接近 100 %。
  C0=12.5 % 时转变对回收率影响小得多，但曲线形状仍不同（结壳时无恒速期，呈抛物线）。
- **patchy 增强蒸发**（§3.7，Fig 2f）：300 µm、25 % 的干燥速率高于纯水，尽管 a_w≈0.75 预期降 26 %。
  解释：盐结构多孔、毛细泵吸、扩大交换面积；壁面爬盐也贡献。
- **成核位置**（§3.3）：周边通量发散 j(r) ∝ [1−(r/r_c)²]^−1/2（咖啡环型），周边局部 Pe 最高，盐从周边向中心蔓延。
- **起始时间**（§3.4，Fig 7）：式(6) C_sat = C0[1 + Pe²τ/(1−Pe τ)²]，Pe=2.8 时高估起始时间；粒径越小起始越晚。
- **非单调性**（§3.8，Fig 10）：50–62 µm 上蒸发率随 C0 非单调，C0=18 % 最低。
- 无明显 subflorescence（§3.5）。

## §4 毛细柱模型（供液上限）

假设：盐结构为直径 d_e=d、高 h_e 的多孔圆柱，间距 a≈2d，孔隙率 ε_e 与粒径无关；盐结构孔径 = b × 基底孔径；
屏蔽使蒸发集中在柱顶，j_e ≈ 5j。

    K_e = b² ε_e³ d² / [180(1−ε_e)²]                       (Carman–Kozeny)
    P_ce = c(1−ε_e)γ / (b ε_e d)，  P_cpm = 6(1−ε)γ / d
    j_e = ρ_l (K_e/μ) [ (P_cpm − P_ce)/h_e + ρ_l g ]        (11)
    h_e = γ d [ c(1−ε_e)/(b ε_e) − 6(1−ε)/ε ] / [ ρ_l g d² + j_e ν (1−ε_e)²/(b² ε_e³) ]   (12)
    h_e/d = [ c(1−ε_e)/(b ε_e) − 6(1−ε)/ε ] / (B + Ca)                              (13)
    B = ρ_l g d²/γ（Bond），Ca = j_e ν (1−ε_e)² / (b² ε_e³ γ)（毛细数，黏性 vs 毛细）

参数（**全部为假设**）：ε_e=0.04，ε=0.36，c=6e−2，b=1e−2，j≈1e−4 kg/m²/s。
结果（Fig 14）：大珠 h_e 厘米级；<100 µm 急剧下降；26 µm 时 2–3 mm。

**预言**（§4 末、结论 8）：同一粒径下增大 j 也应转为结壳；减小 j（提高 RH）细珠也可 patchy。有初步实验支持。
**作者自陈的局限**：参数可疑；假设盐结构随粒径自相似；忽略 Kelvin 效应。

## 对我们模型的用法

- 供液门控的**形式**（毛细 vs 重力 + 黏性）取自此处，但**参数一律不取**（ε_e=0.04、b=1e−2 是演示值）。
- 形貌判据必须含 j：这是式(13) 中 Ca 的物理内容，也是本知识库 README 里"RH 张力"的解。
- 验证数据：Fig 2（6 档粒径 × 3 浓度的质量曲线）、Fig 8（回收率 vs 粒径）、Fig 7（起始时间）。均为 drying。
- 与 Ben Amara 2025 的差异：T 30 vs 21 °C，RH 3 vs 7 %，珠径档不同；两者转变粒径一致（细档结壳）。
