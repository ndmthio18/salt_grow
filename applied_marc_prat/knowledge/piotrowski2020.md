# Piotrowski, Huisman, Nachshon, Pohlmeier, Vereecken (2020) —— 盐壳的气体渗透率直接测量

*Gas Permeability of Salt Crusts Formed by Evaporation from Porous Media.* Geosciences 10, 423. 文件：`literature/geosciences-10-00423-v2.pdf`
资助：DFG SFB 1313（与本组同一 CRC，Jülich IBG-3）。

**regime：drying**（砂柱初始饱和，底部不供液）。**这是文献中唯一对分离盐壳做的直接渗透率测量。**

## 实验条件

| 项 | 值 |
|---|---|
| 基底 | F32 石英砂，平均粒径 **240 µm**（49 % 在 180–250 µm），φ=0.37±0.01，干砂 k=**2.10e−11 m²**（气测） |
| 容器 | PMMA 圆柱，内径 31 mm，填高 80 mm |
| 溶液 | NaCl 2.04 M（=33 % 溶解度）；另 MgSO₄ 0.96 M、Na₂SO₄ 0.47 M、纯水各三份 |
| 环境 | T=25±1 °C，RH **20–40 %**，风扇通风 |
| 终止 | NaCl 与 Na₂SO₄ 在 9–17 天、柱内饱和度 20 % 时分离盐壳；MgSO₄ 60 天、30 % |
| 测量 | 移走壳下砂，壳留在壁上；干氮气 0/100/200/300 mL/min，Darcy 式 k = μ s Q/(A Δp)；湿态与 60 °C 烘 96 h 后干态各测一次 |

## 结果

| 量 | 值 | 备注 |
|---|---|---|
| NaCl 壳**干态**本征渗透率 | **4.77e−12 m²**（均值，三份，样本约 2e−12–6e−12） | Fig 5b |
| NaCl 壳湿态气体渗透率 | 与干态相近 | 烘干失重 20 %，说明残留水在不导气的孔里 |
| 文献对照 | 3.7e−12（Nachshon 2018，μXRCT + LBM，5 wt %）；4e−12（Nachshon 2011，再饱和法，饱和溶液） | 三种 C0（0.89–6.13 M）下一致 → **NaCl 壳本征 k 对初始浓度不敏感** |
| 壳/砂渗透率比 | 4.77e−12 / 2.10e−11 = **0.23** | |
| NaCl 壳厚 | 1.5–2.7 mm（均值 1.9、2.3 mm），周向偏差 ≤26 % | Table A1；穹顶下的空气腔不计入 |
| 壳形态 | 白色 efflorescent，部分脱离砂面成穹顶，"柱"之间有空气（引 Nachshon 2018 μXRCT） | Fig 3g |
| MgSO₄ 壳 | 干态 3.53e−12，湿态 3.52e−14（差两个量级） | subflorescent，几乎封住蒸发 |
| Na₂SO₄ 壳 | 干态 7.57e−12，湿态 4.30e−12 | 首次测量 |
| 蒸发率（NaCl） | 初始 12.1 mm/day（纯水 18.3）；第 2–3 天平台 4.1→2.7 mm/day（SS2）；第 9 天 <1 mm/day | Fig 2b |
| 壳下砂与壳本身 | 分离时均为湿 → 毛细连接保持到最后 | |

**作者结论**：本征渗透率只能部分解释壳对蒸发的影响（MgSO₄ 壳 k 不低却几乎封死蒸发）；需要壳的非饱和性质
（保持曲线、相对渗透率）与蒸发前沿位置。建议用 μXRCT 做孔尺度模拟。

## 对我们模型的用法

1. **patchy 分支的 k_s 得到直接测量支持**。按继承标度律（d_c=0.14 d_sub，孔≈d_c/4）对 240 µm 砂算：
   CK 给 1.6e−12、立方律给 1.4e−12 m²，测量 4.8e−12，差 3 倍，属粗糙 stereology 的正常偏差；
   "k_s ≈ 0.1–0.3 × 基底 k"的经验规则被测量比 0.23 直接命中。
2. **"crust"一词跨 regime 混用，必须警惕**。本文的 NaCl "crust" 长在 240 µm 砂上，按 Eloukabi 2013 的阈值（≥200 µm）属于
   patchy 合并成的 efflorescent 层，孔径微米级、k≈5e−12；2014/Licsandru 在 1–50 µm 珠上的纳米孔 crust k≈1e−22。
   两者相差 10 个数量级，不是同一种结构。写作时区分"coalesced efflorescence layer"与"nanoporous crust"。
3. **蒸汽阻力**：微米孔、2 mm 厚的层，其扩散阻力 h_c ε^1.5 /δ 很小，不足以解释蒸发降幅；本文 NaCl 的降幅主要来自
   drying 的浓度上升与后期供液，不是壳的扩散阻力。这支持 `porous_salt_parameters.md` §8 的结论：14× 降幅只出现在纳米孔 crust。
4. **可用的验证数据（drying）**：Fig 2 的 NaCl 质量与蒸发率曲线（含初始 a_w 降幅 0.66 与 Table 3 的 0.89 对比）；壳厚 ~2 mm 与
   9–17 天的关系可与生长律粗略对照，但缺 j(t) 的空间分布。
5. **测量方法可复用**：同一 CRC 内有气体渗透仪与 μXRCT，若做自己的验证实验，可按本文流程分离盐壳测 k_s，
   并补测 Ben Amara 型细珠基底上的纳米孔 crust（作者自己提出"更细质地的适用性待研究"）。
