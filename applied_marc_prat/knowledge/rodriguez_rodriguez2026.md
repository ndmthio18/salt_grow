**regime：单向蒸发的玻璃毛细管**（无多孔基底；下端弯月面蒸发，盐在管外表面爬行）。是机制实验，不是多孔介质实验。

## 实验与模型

- 变量：初始盐质量分数 φ_0 = 0.05–0.24，RH H_r = 0.10–0.70。
- 观测：φ_0 = 0.20、H_r = 0.10 时上弯月面**间歇跳跃**，与盐沉积区灰度的"突升–骤降"事件同步——骤降 = 液体**吸入多孔盐沉积**（折射率变）。盐爬行由"蒸发–吸液"反馈维持：沉积的多孔盐网络吸液，液体在外层蒸发再析盐，网络延伸。
- φ_0 = 0.05 或 H_r = 0.70 时平滑；φ_0 = 0.24（近饱和）时自增强爬行但不间歇。
- **微结构随生长模式变**（Fig 3B SEM）：沿壁**轴向爬行**的沉积是**小而致密、准平面排列**的晶体；**径向自由生长**是**大而疏松、高孔隙**的结构。
- 促进成核（粗糙基底）使 φ_eff 降到 φ_del，滞后窗消失，爬行与间歇被抑制。
- 最小模型：管内一维对流扩散（式 1–2）；总失水 J = J_meniscus（式 3，Picknett–Bexon 型）+ J_wick（式 5，经有效扩散长度 δ_v 与有效吸液面积 A_wick）；
  A_wick 按一阶动力学增减（式 6），开关由滞后决定：φ ≥ φ_eff（0.320，异质成核阈值）→ 析出、A_wick 增；φ < φ_del（0.267 ≈ 饱和）→ 溶解、A_wick 减。
  结果是**弛豫振荡器**：出口浓度在 φ_del 与 φ_eff 之间振荡，间歇激活吸液。

## 对模型的用法

| 结论 | 用途 | 限制 |

| 异质成核阈值 φ_eff/φ_sat = 0.320/0.267 ≈ **1.20** | 实验 1 与 V2 的 S_nuc 默认值取 1.2；与 2014 Table 3 首次析出过饱和 1.05–1.26 一致 | 玻璃壁上的异质成核，多孔基底上可能不同 |
