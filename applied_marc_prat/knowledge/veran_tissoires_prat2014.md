## 成核位置（§3–§5）

表面浓度峰的分布由三层非均匀性决定：宏观通量分布（周边效应）、壁面孔隙率效应（Vafai 型 ε(r)，式 3.13）、

## §6.2 格子生长模型（本项目已复现）

气相：ΔX_v=0，湿面 X_v=X_ve，顶 X_v=X_v∞，干盐面零通量（6.1–6.3）。局部 j = −ρD∇X_v·n（6.4）。
沉积：j_cr = j C_sat（6.5），**比例系数隐含为 C_sat，无动力学**。
盐结构内：ΔP_vis=0（6.6），边界 j = −(k_s/μ_s)∇P_vis·n（6.7），
毛细兼容：P_cth ≥ −(P_vis − ρ_l g z)（6.8）；不满足则该格**干涸**：零蒸发、无溶液、成为局部屏障。

算法七步：种子 → 算边界格 J_i → 解压力 → 干涸检查 → 填充时间 t_i = ρ_sc V_i/(J_i C_sat) → 最小 t 者全填、其余部分填 → 循环。
随机性来自每格最大可填体积 V_i 随机（本项目实测：这等价于局部 ε_s∈(0,0.75) 的非均质盐结构模型）。

参数（**演示用假设**）：P_cth = 6(1−ε_s)γcosθ/(ε_s d_bs)，ε_s=0.1，d_bs=100 µm，固定；
k_ref = ε_s³ d_bs²/[180(1−ε_s)²]；只扫 k_s。域 100×80 格。

结果：k_s = k_ref 到 1e−6 k_ref 均 patchy（Fig 26a、27：总蒸发几乎不变，盐面增加与基底屏蔽互补）；
1e−8 k_ref 结壳（Fig 26b、28：J_tot ≈ 无盐面积分数 × J_0，随覆盖下降）。作者明言改 P_cth 也能得同样定性结果。

## §6.3 结壳后为什么蒸发降 14 倍而不是归零

- CK 反算 k_s=1e−8 k_ref 对应等效珠径 ~10 nm，故引入 Kelvin：a_w = exp[−(M_v/RT)(2γcosθ/r)]。
- 若整个表面均匀蒸发，需 a_w≈0.15（式 6.10），对应孔 <1 nm，不合理。
- 替代解释：壳顶开孔稀疏。单孔蒸发 J_pore = 2D d_o (M_v/RT)(P_vs−P_v∞)（式 6.11，Picknett & Bexon），
  100 nm 开孔间距需 264 µm（Fig 29）。结论：**crusty–patchy 转变不只是孔径缩放，微结构几何也变（crust 更致密）**。

## 本项目验证（`../salt_grow`）

- 复现转变窗口 k_s/k_ref ≈ 1e−3 → 3e−5 → ≤1e−5（patchy→crusty→blocked），与论文 1e−6/1e−8 差 2–3 个量级，
  归因于式(6.7) 的量纲歧义（j 是否除 ρ_l，差 1200×）；定性序列稳健。判据 H* = ρ_l k_s P_cth/(μ_s j̄)。
- 生长律已做成可注入接口（`GrowthLaw`：deposition_rate + supply_demand），接 PNM 的缝就在这里。
- 方向剖析：方向由蒸气场决定，随机容量只管分叉，干涸管改道；汇的远近不影响形貌。
- 去随机后的确定性版：对称针，失稳谱无最快波长，格距即正则化。
