# Figure 8 — 与 Norouzi Rad et al. 砂柱实验对比

`../.venv/bin/python run.py` → `fig08.png`（需先跑 `../digitize.py`）

## 对应论文内容

(a) 式(35)：$\dfrac{dM_s}{dt}=\dfrac{\rho C_{eq}U_{evap}}{1-C_{eq}}\eta A\,F(Da^*)$
(b) 式(32) 的 $dh/dt$，把 (a) 换算成等效厚度 $h_{equ}$。

实验来自 **Norouzi Rad, Shokri & Sahimi, Phys. Rev. E 88, 032404 (2013)**（ref 18），
砂粒 0.17–1 mm（均值 0.58 mm），6 Molal NaCl。

## 缺失的 A，以及怎么绕过去

式(35) 需要实验圆柱截面积 $A$，**Prat 论文没给**（它在付费墙后的 ref 18 里）。
但 (a) 和 (b) 画的是同一组实验的不同单位，二者由
$M_s=\rho_{cr}(1-\varepsilon_s)h\,\eta A$ 相联。所以把两张图都数字化就能反推 $\eta A$，
不需要任何外部数据。

**反推结果与交叉校验**：

| 量 | 值 |
|---|---|
| 两次独立提取的 13 个时间点最大偏差 | **0.049 hr** |
| 反推 $\eta A$ | **0.7187 cm²** |
| 13 个点的相对标准差 | **0.29%**（验收阈值 5%） |
| 取 $\eta=0.76$ → $A$ | 0.946 cm²，等效直径 **1.10 cm** |

0.29% 的离散度说明两次数字化都可靠——如果任何一次有系统偏差，$\eta A$ 就不会是常数。
1 cm 量级的砂柱对 X 射线显微断层扫描样品完全合理，所以反推值物理上说得通
（ref 18 付费墙，未能直接核对）。

## ⚠ 什么是独立验证、什么不是

因为 $\eta A$ 是从两张图的**比值**得来的，**panel (a) 是 panel (b) 的单位换算，
不构成第二次独立验证**。真正独立的检验是 (b) 的**斜率**——它等于式(32) 的 $dh/dt$，
不含任何拟合量：

| | 值 |
|---|---|
| 论文线斜率（数字化） | 2.4865 mm/day |
| 我方 core（式 32） | **2.4885 mm/day** |
| 比值 | **1.0008 → 吻合到 0.08%** |

**这是整个项目最强的一条验证**：它同时确认了 $a_v$、$D_{s,eff}$、$Da^*$、$F$ 的实现，
以及反标定的 $\rho = 1200$ kg/m³（前因子 $\rho C_{eq}/[\rho_{cr}(1-\varepsilon_s)(1-C_{eq})]$
线性依赖 $\rho$，若 $\rho$ 错 10% 这里就会差 10%）。

## 质量速率对照

| | 论文线 | 我方 |
|---|---|---|
| $\eta=1$ | 11.860 mg/hr | 12.128 mg/hr（差 2.3%） |
| $\eta=0.76$ | 9.209 mg/hr | 9.217 mg/hr（差 0.09%） |

$\eta=0.76$ 那条必然吻合（$A$ 就是用它反推的，自洽）。有意思的是**论文自己两条线的
斜率比是 0.7765，而不是 $\eta=0.76$** ——按式(35) 二者应严格成比例。这 2% 的偏差
要么来自论文制图，要么来自数字化精度，量级都很小。

## 一个必须注意的实现细节

**论文的模型线不过原点**，而是从第一个实验点 $(5\ \mathrm{hr},\,0.06\ \mathrm{g})$ 起画
（盐霜要等表面达到饱和才开始长）。本复现照做，否则无法与论文并排比较。
这与 Fig 9b 相反——那里的线是过原点的。

$\varepsilon_s$ = 0.43，$k_r$ = 2.3×10⁻³ m/s，$\eta$ = 0.76。
