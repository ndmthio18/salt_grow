**体系**：evaporation-wicking。**分支** `surface-first`（自 baseline-selfconsistent 72ee682），工作树 `../salt_grow_v2-surface`。
生产守恒内核是 `saltv2/pnm/transport.network_step`；Stage-T 的 `conservative_step` 只保留作交叉验证。

## 0. 内核交叉验证（plan/19 §6 步骤 1，2026-10-26）

`kernel_crossval.py` → `results/kernel_crossval.md / .json`；测试 `tests/test_kernel_crossval.py`（2 项）。
两内核方程相同（液体储存项 + 守恒形式盐），区别在喉道通量密度的时间取法：`network_step` 用 tⁿ 密度，`conservative_step` 用迭代的 tⁿ⁺¹ 密度。
按决定**不要求逐位一致**，比较三件事：

| 算例 | 尺 | network_step | conservative_step |
|---|---|---|---|
| 单柱 1×1×50，均匀需求 | 累计盐残差 / 增盐 | −4e−15 … −2e−13 | ≤ 6e−11 |
| | 累计水残差 / 蒸发 | ≤ 3.5e−9（`STORAGE_RTOL` 1e−12 的界） | ≤ 5.5e−11 |
| | t_sat @ dt 30 s | 1.917636 h | **1.917673 h = Stage-T 参考**（差 1.7e−3 s，即参考值 6 位小数的舍入） |
| | t_sat 差（60/30/15/7.5 s） | 0.273 / 0.137 / 0.068 / 0.034 s：**严格减半，一阶** | |
| | Richardson 阶 / 极限 | 1.00 / 1.915713 h | 1.00 / 1.915713 h（极限差 < 1e−4 s） |
| 热点 5×5×10 | 同上 | 盐 ≤ 2e−11，水 ≤ 2.5e−9；阶 1.00，极限 1.479594 h | 盐 ≤ 8e−12，水 ≤ 6e−12；阶 1.00，极限 1.479594 h（差 2e−4 s） |

**判定**：守恒与接口验证通过。两内核是同一方程的一阶一致离散，极限相同；`network_step` 作为唯一生产内核，Stage-T 的工具
（`throat_kind / drop_throats / step_residuals / hydrostatic_head`）随 `pnm/conservative.py` 移入并导出。
`network_step` 的水残差比盐残差大三个量级，是其收敛判据（密度相对 1e−12）而非方程的问题；若 S1 需要更紧的水账，收紧 `STORAGE_RTOL`。

**未做**：非零盐汇（`crystal / w_eq` 互补形式）的一步守恒测试（plan/19 §6 步骤 3），S1 前补。

### 1.2 优先级 1：接口守恒（`tests/test_interface_conservation.py`）

`network_step` 新增 **opt-in** `crystal_liquid_sink`：被保持在 C_sat 的孔失去的盐 X 同时是其液体账的汇（孔仍充满液体，网络要送 X 的盐水补上），
X 随 ρ' 一起迭代。默认路径逐位不变（改动前后 3×3×6 网络 40 步的输出哈希一致）。

| 账 | 定义 | 有汇（S1 约定：q_mass = 纯水） | 无汇（默认） |
|---|---|---|---|
| 溶解盐 ΔΣm − (salt_in − X) | 盐方程 | ≤ 1e−22 kg / 步 | ≤ 1e−22 |
| 固体盐 X | 互补形式，≥ 0 | 从第一步起 X = C_sat/(1−C_sat)·q·dt（饱和柱，无瞬态），相对 1e−12 | X = C_sat·q·dt |
| 总液体 ΔΣVρ − (liq_in − q − X) | | ≤ 1e−22 | 差 X |
| 水 Δ(L−S) − (liq_in − salt_in − q) | | ≤ 1e−22（相对库存 1e−16） | **每步凭空产生 X 的水**（本例为蒸发水量的 26 %） |

生产约定里 q_mass 已含表面所取盐水的盐份，违反量是 X − C_sat q_mass dt（瞬态非零，稳态为零），由驱动的接口缓冲吸收；
生产是否切到有汇版本会改运行记录，留给批量重跑。欠饱和盐库（C0 = 0.25）下互补形式保持 X ≥ 0，四本账同样关闭。
籽晶：结构的第一份质量就是孔被保持后第一步的 X（含越过 C_sat 的那点过量），无注入。**通过。**

读法：
- 盐库饱和时柱内无瞬态，孔口每蒸发 1 kg 水送出 C_sat/(1−C_sat) = 0.3587 kg 盐（X/E 0.396 多出的是填充新孔的盐水所带的盐 C_sat q_fill），
  dh/dt 与 `prat2026.core.growth_rate`（式 29）一致到 1e−9（测试 rtol 1e−9）。前沿 / 内部沉淀份额 = F / (1−F)，固体总量 = ΣX − C_sat·M_liq 到 1e−12。
- C0 = 0.25 时柱送到的盐少于换算（X/E 0.32 < 0.36），生长比式 29 慢 16–19 %：这是**供给**陈述（向下扩散与 0.25 的来流），不是动力学。
- E(end)/E0 > 1 是湿结构逼近远场平面（h 0.5 mm 对 δ_eff 18 mm），不是屏蔽（plan/19 §3.4）。
- **生长期的原型误差远大于 t_sat 期**：h(24 h) 对 D-50 偏高 +10.5 %（D-10）、+5.8 %（D-15）、+1.06 %（D-25），每多解析 10 层误差约减半。保持在 C_sat 的孔靠整根柱供盐，向下扩散到储量里的盐在 24 h 内回到表面；集总段没有储量，于是多送盐。t_sat 只看 3 mm 的扩散长度，生长看整根 35 mm。
