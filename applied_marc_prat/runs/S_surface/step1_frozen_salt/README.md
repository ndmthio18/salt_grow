# Step 1：给定湿外部几何（冻结盐柱）对单孔蒸发的影响（gas-only）

分支 `verify/step1-frozen-salt-pillar`，父提交 a23cb78（`verify/step0-single-pore-evaporation`，GitHub 与 origin 同值）。
执行记录：`run.py --solver cg`（约 11 s）→ `results/`；`plot.py` → `figures/`；测试 `tests/test_step1_frozen_salt.py`。
案例模块 `saltv2/cases/step1_frozen_salt.py`。本研究是 **evaporation from prescribed wet external geometry**：不模拟盐材料内部的液体输运、干化或晶体排列；柱高与湿/惰性面状态都是给定的测试条件。

## 1. 物理系统与边界条件

Step 0 的气相问题（T = 295.15 K，RH = 0.07，饱和盐水 C = 0.264，a_w = 0.75305，540 µm 正方形孔口，700 µm 周期格元，远场 δ_eff = 20.6 mm，标定值）加一个以孔口为底、高 h 的正方棱柱：

    div(rho_g D_v grad X) = 0,    j = -rho_g D_v grad X

- 湿面：X = a_w(C_sat) W_sat(T) = 0.0125166（供给无限）；惰性面与基底：零法向通量；横向周期；远场 X = RH·W_sat = 0.00116349，位于 z = δ_eff。
- 柱下的孔口被覆盖，**不**作为第二个蒸发面（柱体素非气相格，底面无 Dirichlet）。
- A0：h = 0，裸孔口。A1：顶面湿、四个侧面惰性。A2：顶面与四个侧面都湿。h = 0 时 A1、A2 按构造退化为 A0（同一组面）。

## 2. 数值实现与面处理审计

`growth.vapor.solve_vapor` 把 SALT_WET 体素的**所有**暴露面都设为湿面，不能表示 A1。按指令未改生产内核，案例模块写了**面选择装配** `solve_faces`：柱体素从域中移除（`fv.assemble_laplace`，无内部 Dirichlet、无底 Dirichlet），只在选定的（气相格，方向）面上加 `fv._half_scale` 的半格 Dirichlet 导度 ρD·a²/(a/2)。每个物理面恰好计一次（顶面：柱上方一层气相格的下面；侧面：与柱体素横向相邻的气相格朝柱的面）。惰性面没有任何项，通量为零是构造结果。

对生产内核的交叉验证（`cross_check`，结果 `step1_results.json`）：

## 5. 物理解释（分开四个效应）

1. **界面抬高**（A1）：R_height 与一维平面对照 δ_eff/(δ_eff − h) 在 1e−4 内一致（0.5 mm：1.02493 对 1.02488）。原因是远场阻力主导：δ_eff = 20.6 mm 对格元 0.7 mm，孤立顶面的扩展阻力（Step 0：折合 74 µm）几乎不随 h 变化，顶面上升 h 就少走 h 的一维路程。A1 顶面平均通量随 h 从 2.660 升到 2.727e−5。
2. **增加湿侧面**（A2 对 A1）：R_sides = 1.0011–1.0012，与 h 几乎无关。侧面把近场扩展阻力再降一点，但总量由远场定。侧面吸走总量的 27 %，顶面通量相应降到 1.97e−5（−27 %），而 E_side ≈ 2.1e−12 几乎**不随高度增长**：侧面通量集中在顶棱附近（max/mean 从 2.9 到 13.3），下部侧面几乎不蒸发（图 3 右下，z < 0.15 mm 处通量 < 顶面均值的 5 %）。湿面积增至 4.7 倍（0.5 mm）而 E 只增 0.12 %：**湿面积增益不等于蒸发增益**。
3. **外部有效传质边界**：以上两条都依赖 δ_eff ≫ 结构尺寸这一标定设定。20.6 mm 吸收了实验的外部对流，不是实际 20.6 mm 静止空气层；若实际外阻小得多，近场几何的权重会大得多。本步不能对实验的蒸发增强作任何陈述。
4. **周期像**：结果是 700 µm 节距的孔阵列，不是无限平面上的孤立孔。2 mm 盒顶的横向非均匀度在 Step 0 为 5e−10，域截断检查确认几何改变后仍精确；横向周期未扫描。

**Step 1 总判定：PASS。**

**NUMERICAL LIMITATIONS**：20 µm 主算用 CG（rtol 1e−12），不是直接法；局部通量只在两种体素间比较，无收敛声明；柱顶棱处的通量奇点（max/mean 2.8，侧面 13）在体素网格上必然欠分辨，局部极值依赖网格；横向周期固定 700 µm。

**PHYSICAL ASSUMPTIONS**：面状态给定、供给无限；柱内无输运；等温、无对流；δ_eff 标定；a_w 为 25 °C Pitzer；ρ_g 单一常数；柱底面积 = 孔口面积。

**QUESTIONS FOR THE NEXT STAGE**：(i) Prat 律用局部 j：顶面与侧面的 j 相差一个量级且侧面 j 随 h 按 ~1/h 衰减，"结构表面的 j" 必须按面定义；(ii) 在 δ_eff 主导的参数化下，任何外部几何都只改变 E 百分之几，蒸发反馈对生长的作用主要是重新分配而非增量——这应在引入生长前明确；(iii) 若需评估实验的蒸发增强，必须先独立约束外部阻力的尺度。
