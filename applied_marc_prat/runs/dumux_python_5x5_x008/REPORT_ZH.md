# 5×5 DGF 的 DuMux–Python PNM 验证报告

## 结论

**总判定：NO-GO。** 当前结果不能支持“Python 单相 PNM 已被 DuMux 验证”的结论。

最根本的问题不是两套代码的数值离散误差，而是受比较的物理状态不一致：DuMux 虽以
`Sliq=1` 初始化，但最小液相饱和度在 100 s 已降至 0.970683，在无固盐的 900 s 已降至
约 0.74395；Python PNM 则始终假定孔隙被液体充满。因此，本轮 DuMux 计算并不是所需的
“全液相极限”。通量回放没有消除浓度差，进一步排除了“仅由蒸发闭合不同造成差异”的
解释。

Float64 诊断还显示，名义 Dirichlet 的底部五孔 NaCl 摩尔分数也未严格保持 `0.08`：到
1000 s 最大绝对漂移为 `3.069×10⁻4`。因此“固定组成储液池”条件也未被当前 DuMux 解严格
实现，这会污染储液池通量和台账比较。

DuMux 两个正式计算也都未到达 40000 s：5 s 档在约 27340 s 因奇异线性系统和 Newton
失败而 abort；10 s 档在约 27374 s 将时间步持续缩小至 `3.08×10⁻173 s`，物理时间不再
前进，因而被终止并登记为数值失败。40000 s 只有 Python 结果，不存在可诚实制作的
DuMux–Python 终态差值图。

## 输入与几何

- DGF：`input/N5x5_R270um_SD10um_L3.5mmx3.5mm_n1_top_varthroat.dgf`
- SHA-256：`E48FF929AEAE9149DF9B575FD2BD612C7C19E111810D023DBF7013EE5341B825`
- 原始孔：30；动态孔：25；底部储液池孔：5；顶部蒸发孔：5。
- 原始喉道：45；动态孔内部喉道：36；跨储液池边界喉道：5；被忽略的储液池横向喉道：4。
- 初始/储液池 NaCl：`x=0.08`，Python 内部 `w=0.22001805096761068`。
- `T=293.15 K`，远场水蒸气摩尔分数 `0.0047`，边界层 `1.6 mm`，无重力。

几何测试全部通过，且原一维读取测试未发生回归。

## 判据结果

### 时间步与运行完整性

| 检查 | 结果 | 阈值 | 判定 |
|---|---:|---:|---|
| Python 10 s–5 s，最大 `|Δx|` | `1.08534×10⁻4` | `<1×10⁻4` | FAIL |
| Python 10 s–5 s，累计蒸发相对差 | `8.57×10⁻6` | `<0.5%` | PASS |
| Python 10 s–5 s，固盐相对差 | `0.338%` | `<1%` | PASS |
| Python 5 s–2.5 s，最大 `|Δx|` | `5.58727×10⁻5` | `<1×10⁻4` | PASS |
| Python 5 s–2.5 s，累计蒸发相对差 | `4.28×10⁻6` | `<0.5%` | PASS |
| Python 5 s–2.5 s，固盐相对差 | `0.171%` | `<1%` | PASS |
| DuMux 10 s–5 s，27300 s 最大 `|Δx|` | `7.361×10⁻3` | `<1×10⁻4` | FAIL |
| DuMux 两档到达 40000 s 且 Newton 全收敛 | 否 | 必须 | FAIL |

Python 的 5 s 主档相对补充的 2.5 s 档已收敛，但预注册的 10 s–5 s 总体判据仍失败。
DuMux 的 27300 s 比较已经接近奇异终止区，不能用蒸发量和固盐量两项偶然较小的差异替代
浓度与运行完整性失败。

### 首次沉淀前

为保证两档均未出现固盐，逐孔/逐喉误差在 900 s 比较；首次饱和另用 DuMux 5 s 高频
诊断插值。

| 检查 | 结果 | 阈值 | 判定 |
|---|---:|---:|---|
| 自洽闭环最大 `|Δx|` | `3.56309×10⁻3` | `<5×10⁻4` | FAIL |
| DuMux 通量回放最大 `|Δx|` | `3.71928×10⁻3` | `<1×10⁻4` | FAIL |
| 自洽闭环累计蒸发相对差 | `1.024%` | `<2%` | PASS |
| 首次饱和时间：DuMux / Python | `934.515 / 1279.317 s` | 相对差 `<3%` | FAIL（36.90%） |
| 有效喉道流向一致率 | `6.82%` | `100%` | FAIL |
| 有效喉道流量加权相对误差 | `2905.8%` | `<2%` | FAIL |
| 表压加权相对误差 | `2095.9%` | `<2%` | FAIL |

回放使用 DuMux 五个顶部孔各自的蒸发通量。回放误差没有下降，故差异主要来自内部状态/
输运闭合，而非顶部水蒸气边界。更严格地说，由于 DuMux 在 900 s 已是气–液两相，该结果
不能被解释为两个单相求解器之间的输运误差。

有符号 Float64 通量还显示，900 s 的 44 条有效喉道中只有 3 条与 Python 流向一致；这不是
VTP 丢失符号造成的伪差，而是两相排液状态与液体充满供液状态的直接差别。

### 沉淀反馈与台账

由于 DuMux 未到达 40000 s，下面的“末态”仅指最后共同保存时刻 27300 s，不是计划中的
终态验收。

| 检查 | 27300 s 结果 | 计划阈值 | 判定 |
|---|---:|---:|---|
| 总固盐相对差 | `25.04%` | `<5%` | FAIL |
| 孔固相率最大绝对差 | `0.2103` | `<0.02` | FAIL |
| 最小喉径相对差 | `4.080%` | `<2%` | FAIL |
| Python 盐台账相对残差（5 s） | `7.36×10⁻15` | `<1×10⁻8` | PASS |
| Python 水台账相对残差（5 s） | `6.150%` | `<1×10⁻8` | FAIL |
| DuMux 重建水台账，0–1000 s 最大相对残差 | `0.1958%` | `<1×10⁻6` | FAIL |
| DuMux 重建 NaCl 台账，0–1000 s 最大相对残差 | `3.367%` | `<1×10⁻6` | FAIL |

Python 在未沉淀的 900 s 通量回放中，水台账相对残差为 `1.15×10⁻12`；进入沉淀后，5、
2.5 s 档的水残差分别为 6.150% 和 6.162%，没有随时间步减半而消失。该证据把问题定位到
当前“缩小液体孔体积—下一步再施加排液体积源”的沉淀耦合，而不是一般的输运守恒。
盐台账仍保持机器精度。

DuMux 另用验证专用 Float64 状态、直接组分库存和有符号的两相组分通量，以 1 s 强制检查点
重建右端隐式通量台账；在 940 s，水和 NaCl 相对残差分别为 0.1690% 和 −3.030%。这仍远高于
`10⁻6`。该诊断只覆盖 0–1000 s；失败的正式长算例生成于有符号诊断加入之前，不能据此
声称全程台账闭合。

## 压力场

主压力图包含 1000 s、DuMux 首个含固盐的 5 s 检查点 940 s，以及最后共同保存时刻
27300 s。每行均为 DuMux、Python、`Python−DuMux`；30 个孔和 45 条喉道全部重建，孔径和
喉径分别控制圆直径和线宽。蓝色边框为储液池孔，红色边框为蒸发孔。

颜色量为表压 `Δp=p−p_res`，各模型使用自己的储液池液压参考；Python 为 `1.0×10⁵ Pa`，
DuMux 在 100 s 的 Float64 参考约为 `99462.25288 Pa`，随后按各时刻底部五孔平均值计算。
CSV 同时给出表压、绝对压力和参考压力。

940/1000 s 使用验证提交直接输出的 Float64 压力和有符号流量，不再依赖 VTP 的 Float32
绝对压力。正式长算例是在该诊断加入前完成的，27300 s 仍须用
`volumeFluxW/transmissibilityW` 重建；其全程最大相对重建残差在失败前升至 31.37%。因此
940/1000 s 图可用于本判据比较，27300 s 压力图只能作为数值失稳诊断，不能作定量物理结论。

40000 s 另提供 Python 单模型压力图。它不能替代缺失的 DuMux 终态，也不计算伪造的差值。

## 可支持与不可支持的科学结论

本轮可支持：

1. DGF 的多储液池消元和原始索引映射实现正确，完整网络可重建并输出逐孔、逐喉状态。
2. Python 5 s 结果相对 2.5 s 已达到规定的时间步精度；无沉淀阶段的水盐台账闭合。
3. 当前 DuMux 配置很早离开全液相，且后期趋于近干和奇异；它与液体充满的 Python PNM
   不是同一物理问题。
4. 沉淀后的 Python 水台账没有闭合，当前沉淀–孔体积反馈不能作为守恒验证通过。

本轮不支持：

- 不支持“Python 单相 PNM 经 DuMux 验证”。
- 不支持 40000 s 双模型终态、排水、弯月面移动或干燥阶段的外推。
- 不支持用晚期压力场拟合或校准 Python；DuMux 晚期压力重建本身已受奇异状态影响。

下一轮若要做真正的单相验证，应先使用明确的单液相 DuMux 方程/约束，使 `Sliq=1` 在整个
无沉淀基准中保持不变，并直接输出有符号的液体、NaCl 和水的储液池喉道通量；在该基准通过
后，再以隐式、同一步水守恒的方式加入沉淀体积反馈。真正的两相验证应另立任务，不与单相
PNM 验证混称。
