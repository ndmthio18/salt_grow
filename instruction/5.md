# Phase 1.1 — Review Fixes and Spatial Growth Readiness

Repository: `ndmthio18/salt_grow`

Branch: `phase1-evaporation-mass-budget`

Reviewed commit: `7039ef7`

The Phase 1 evaporation and mass-budget implementation has passed the initial scientific code review, subject to the issues below.

Your next task is to address these issues and prepare a clear numerical interface for Phase 2.

Do NOT implement the actual 3D CA growth algorithm yet.

## Task 1 — Domain capacity and growth feasibility

The reference case uses:

- Grid: 64 × 64 × 64
- Voxel size: 10 µm
- Temperature: 298.15 K
- RH: 0.30
- Duration: 24 h

The predicted salt volume exceeds the computational domain volume.

Independently verify and report:

1. Total computational domain volume.
2. Initial seed solid volume, if present.
3. Cumulative precipitated salt volume.
4. Solid-volume fraction relative to the computational domain.
5. Time when the theoretical fully solid domain capacity would be reached.
6. Required domain height for representative solid packing fractions of 0.3, 0.5, and 0.7.

Implement a lightweight capacity-diagnostic function.

This function must detect when the predicted solid inventory cannot fit into the prescribed domain.

It must also support a configurable maximum permitted solid-volume fraction to reserve space for porosity.

Do not silently truncate or discard salt mass.

This is a domain-feasibility diagnostic only; it is not a substitute for actual geometric occupancy checks in Phase 2.

## Task 2 — Prepare transactional mass allocation

Review `MassToVoxelAllocator`.

Currently, the allocator immediately records newly allocated voxels in the cumulative budget.

This is correct for Phase 1 numerical accounting but will become problematic once actual geometric growth is introduced.

In Phase 2, the number of requested growth voxels may exceed the number of eligible spatial sites.

Define and document a proposed interface separating:

1. Available precipitation mass.
2. Requested solid voxels.
3. Actual successfully created solid voxels.
4. Unallocated mass.
5. Mass remaining in solution or a deferred precipitation state.

The geometry update must be confirmed before its solid mass is committed.

For Phase 1.1, provide an interface design and executable tests for the accounting invariants if practical. Do not implement spatial CA growth yet.

Do not treat mass that cannot precipitate because of a physical constraint as automatically precipitated solid.

## Task 3 — Reproducibility improvements

Fix the following small issues:

- Make reference time-series generation depend on the configured total duration and physical timestep.
- Avoid an unintentional hard-coded 1441-point time grid.
- Make SVG outputs deterministic by removing or fixing generation timestamps and any non-deterministic SVG identifiers.
- Ensure the resulting reference output hashes are reproducible within the same documented software environment.
- Preserve the existing numerical reference results.

## Task 4 — Additional verification tests

Add tests covering:

1. Capacity overflow detection.
2. Multiple domain heights.
3. Different allowed solid-volume fractions.
4. Existing seed volume accounting.
5. A precipitation mass request larger than available geometric capacity.
6. Zero-growth cases.
7. Cumulative mass conservation under variable relative humidity.
8. Repeated sub-voxel mass allocations.
9. Consistency between requested, realized, and unallocated mass in the proposed Phase 2 accounting interface.

For zero or insufficient spatial capacity, the model must return an explicit status rather than creating fictitious solid voxels.

## Task 5 — Define the Phase 2 physical state model

Prepare a short technical design document for the future 3D CA.

At minimum, distinguish:

- Original PNM solid substrate.
- Existing precipitated NaCl crystal.
- Liquid-accessible pore space.
- Air-filled space.
- Eligible crystal-growth sites.

Evaluate whether these should be represented by a single state array or separate material, phase, and eligibility masks.

Specify how to initialize multiple crystal seeds on the PNM surface.

Explain how a candidate growth site will be selected using local crystalline coordination while enforcing liquid-supply eligibility and the available salt mass budget.

The initial Phase 2 model may use a simplified continuous-wetting assumption, but the assumption must be explicit and testable.

Do not implement pore-network transport, permeability calculations, or a vapor diffusion solver.
